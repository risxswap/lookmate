# 中间件版本对齐开发环境

日期：2026-10-20。状态：已确认，版本约定与相关文档已同步。

## 背景与决定

登录注册模块已在 MySQL 8.0.45、Redis 7.4.11 开发环境中验证。用户要求中间件版本改为开发库版本，因此以 MySQL 8.0.45 和 Redis 7.4.11 作为项目基线，替代此前的 MySQL 8.4 LTS、Redis 8.2.x 规划。

MySQL 继续保存业务数据，Redis 首版仍仅保存登录会话。Nginx 沿用 1.30.x 稳定分支；本轮没有新的 Nginx 开发环境版本依据。

## 影响与验证边界

现有连接配置已指向上述开发环境，本次更新版本约定、架构与数据库设计、模块需求和运行说明，无需改动应用依赖或 SQL。数据库驱动、Spring Session 和 Flyway 的版本继续沿用现有配置，不与服务端版本号混用。

当前尚无 MySQL／Redis 部署 Compose 或镜像配置可修改，后续部署固定上述补丁版本及具体镜像标识。没有对运行中的中间件执行安装、升级、降级或迁移。已完成的登录注册验证证据继续有效；生产部署、HTTPS 与可信代理仍待验证。

当前基线见 [架构设计](../01-项目总览/03-架构设计.md)，实际环境及结果见 [登录注册开发验证](../testing/02-checks/2026-10-20-登录注册.md)。
