# 独立图片处理服务

日期：2026-10-23。

状态：已被同日的 [server 内置衣物抠图](2026-10-23-server内置衣物抠图.md) 替代，以下保留当时的讨论结论，未实施。

## 背景与决定

衣橱新增平铺／挂拍单件衣服自动去背景需求。用户确认在 apps 下增加独立图片服务，采用 apps/image，技术方向为 Python、FastAPI 与 ONNX Runtime。当前实际工程仍为 server 与 web，运营两端继续暂缓。

image 负责一次图片处理，server 通过内网 HTTP 传入图片字节并取得透明 PNG。业务任务、用户权限和七牛存储仍由 server 负责，image 不访问数据库或对象存储，不新增独立任务系统和消息队列。详细有效约定维护在 [架构设计](../01-项目总览/03-架构设计.md#server-内置衣物抠图2026-10-23已确认待实现)，预期行为见 [需求说明](../02-需求文档/2026-10-23-衣物自动抠图/01-需求说明.md)。

## 理由与备选

此前讨论过在 Java server 内通过 ONNX Runtime 推理、浏览器抠图和云 API。独立服务便于单独维护模型依赖、限制推理资源并在后续选择 CPU 或 GPU，代价是增加部署单元和内部 HTTP 调用。当前选择独立服务，不迁移已有图片核验和缩略图逻辑，也不把业务调度拆出 server。

RMBG-1.4 和 BiRefNet 轻量版尚未定型。RMBG-1.4 的公开模型供非商业使用，商业使用需另行协议；BiRefNet 官方模型卡标注 MIT，选定具体权重时仍须核对对应许可。未测试衣物样本，不承诺抠图质量、耗时或最低硬件配置。

参考：[RMBG-1.4 模型卡](https://huggingface.co/briaai/RMBG-1.4)、[BiRefNet 模型卡](https://huggingface.co/ZhengPeng7/BiRefNet)、[ONNX Runtime Java](https://onnxruntime.ai/docs/get-started/with-java.html)。资料已在本轮讨论查阅，后续锁定版本时重新核对。
