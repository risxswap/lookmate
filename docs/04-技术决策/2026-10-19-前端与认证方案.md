# 前端与认证方案

## 背景

首版为桌面浏览器中的个人设计工具，包含大量私有数据查询、编辑和后台任务进度展示。前端需要统一查询状态，后端负责身份和资源归属。

## 决策

- 使用 React、TypeScript、Vite、Ant Design，部署为静态单页应用。按 app、pages、features、components、api、styles 组织代码。
- 使用 TanStack Query 管理服务端数据查询、刷新及任务轮询；表单和弹窗使用组件状态，首版不额外引入 Redux。任务提交关闭自动重试。
- Spring Security 处理认证及接口访问控制，Spring Session 将会话保存在 Redis；Service 校验资源所属账号。
- Cookie 携带会话标识，生产环境启用 HttpOnly、Secure、SameSite=Lax，并保留 CSRF 防护。
- 会话空闲 2 小时失效，从登录起最长 7 天。轮询会延长空闲期，但不延长绝对期限。允许多设备登录，退出仅结束当前会话，不增加首版“记住我”或设备管理页面。
- 使用正确 HTTP 状态码及统一业务 JSON 响应，生成任务创建返回 202 和任务编号。

## 取舍

会话及资源权限由后端控制，前端缓存不作为授权依据。退出时清理当前用户查询缓存；重新登录读取服务端任务状态，不重新提交生成请求。

具体依赖版本及逐接口契约待细化，见 [架构文档](../01-项目总览/03-架构设计.md)和[接口草案](../01-项目总览/05-接口契约.md)。
