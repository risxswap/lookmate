# 小程序穿搭参考详情验证

2026-11-25，在微信开发者工具 2.02.2608080、基础库 3.18.0 中，从「设计 → 穿搭」打开「衬衫牛仔日常」。使用项目图库的正式图片与穿搭说明，图库和收藏请求由隔离数据响应。

| 操作 | 结果 |
| --- | --- |
| 打开详情 | 标题下显示「日常 · 休闲」。390px 模拟器中，主图约 354×472px，人物头部、鞋和「查看大图」都在底部主按钮上方。[穿搭详情](2026-11-25-小程序穿搭参考详情/01-穿搭详情.png) |
| 实点心形，再点主图 | 心形切换空心与实心，收藏、取消各发送一次对应请求。点击主图可打开微信单图预览，退出后回到详情。 |
| 滚动正文 | 能读到配色、轮廓和穿着建议的全部文字。底部仍可点击「用这套穿搭」。[搭配建议](2026-11-25-小程序穿搭参考详情/02-搭配建议.png) |
| 使用这套穿搭 | 进入穿搭设计创建页，已选参考卡片显示「衬衫牛仔日常」。创建页收到参考 ID `casual-denim-shirt` 和版本 `v1`。 |
| 打开无图、已下架和图片读取失败的参考 | 可在占位区收藏。已下架时主按钮禁用。图片读取失败后点击「重试图片」能恢复全身图。 |
