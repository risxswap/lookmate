# 个人资料开发验证

日期：2026-10-21。依据 [需求与契约](../../02-需求文档/2026-10-21-个人资料/01-需求说明.md) 及本轮未提交代码。本记录为开发过程验证，不是生产验收。

## 环境与范围

Java 21.0.8、MySQL 8.0.45；沿用现有 Redis 连接但使用本轮独立会话前缀。新建独立测试库，Flyway V1 migrate 已成功，既有开发库和共享配置未修改。后端使用 18081、前端使用 15173，均绑定本机回环地址。本轮临时配置权限为 600，凭据不进入证据。

前端运行 Node 24.14.0，低于工程锁定的 24.22.0；指定补丁版本待复验。未配置七牛，不将照片数据库夹具和存储替身测试视为真实上传、签名访问或对象删除联调。

## 预期与验证安排

- HTTP 使用 curl 8.7.1，按需求校验名称写入／清空／账号摘要、27 项尺寸完整保存、全空记录、非法数值、历史切换及删除当前值、分页、权限和严格字段。
- 后端集成测试使用真实隔离 MySQL，验证版本并发竞争、事务回滚、历史快照与文件引用保留；测试账号和夹具只属于本轮。
- 页面使用 Codex 内置浏览器执行基础资料保存、尺寸表单及历史操作、版本冲突后保留输入与刷新比较、照片标签和缺配置反馈。浏览器结果单独记录，不由构建结果推定。

## 实际结果

### 自动化和 HTTP

Java 21 下首轮 `LOOKMATE_INTEGRATION=true SPRING_CONFIG_IMPORT=file:/临时配置 ./mvnw verify` 全量 75 项通过；补充严格 JSON 与文件清理场景后，`./mvnw -Dtest=ProfileIntegrationTest verify` 8 项通过并生成最终 JAR。最终分项报告合计 76 项，0 失败、0 错误、0 跳过，见 [测试统计](2026-10-21-个人资料/backend-tests.json)。本轮新增 8 项资料集成测试，涵盖并发单赢家、回滚、名称边界、27 字段、精确小数、历史快照与实际执行清理后的引用保留；存储操作使用替身。

`npm run build` 通过，只有既有主包超过 500 kB 的体积提示。`git diff --check` 通过。

最终 JAR 的 [49 项 HTTP 检查](2026-10-21-个人资料/http-results.json) 与 [1 项 CSRF 检查](2026-10-21-个人资料/http-security.json) 通过。包含初始空状态、名称保存／清空／未传／超长、账号摘要同步、版本冲突、27 字段保存回显、全空新增、负数／零／精度／上限／字符串／布尔值拒绝、历史分页／切换／删除、跨账号尺寸和照片拒绝、照片分类／默认类型检查／部分清空／删除默认引用、缺七牛配置的 503。

照片正向 HTTP 场景使用隔离库中的已核验文件夹具，业务写入和查询经过真实 HTTP、会话及数据库；不代表图片已经上传七牛。所有字段均为本轮合成测试数据。

首次 HTTP 执行因辅助脚本将 Unicode JSON 转义写入 curl 配置，导致反斜线被 curl 解释、名称内容失真。保存 [首次尝试](2026-10-21-个人资料/http-first-attempt.json)，定位为测试脚本编码问题，改为 UTF-8 请求体文件并使用新测试账号执行，未改动产品行为。

### 浏览器

使用 Codex 内置浏览器、1265×712 桌面视口，连接本轮 Vite 与最终 JAR。完成以下实际操作：

- 输入名称并保存，页面身份区及右上角账号菜单同步；见 [资料截图](2026-10-21-个人资料/profile-basic.png)。
- 输入身高 170.125，字段旁显示精度错误且值保持未被舍入；改为 170.25、体重 60.5 后新增历史并设为当前。
- 打开尺寸删除确认，确认文案解释当前引用清空及历史快照保留；取消后记录保持。切换到已有全空历史，刷新后仍为该记录。实际删除提交由 HTTP 和事务测试验证，未宣称浏览器执行了删除。
- 打开照片页，夹具照片因未配置七牛而显示预览失败；设置全身照默认成功，默认标记与清除入口出现。选择本地测试 PNG 后提示图片服务暂不可用，保存按钮禁用；见 [照片截图](2026-10-21-个人资料/profile-photos.png)。
- 通过另一个 HTTP 会话修改资料，旧页面提交收到冲突，输入保留且保存禁用；刷新展示最新名称与尺寸，用户输入保持，重新提交成功。发现并修复刷新成功后旧冲突错误仍显示的问题，再次制造冲突后复验通过，见 [比较截图](2026-10-21-个人资料/profile-conflict.png)。

页面写入还通过独立接口读取确认，见 [持久化证据](2026-10-21-个人资料/browser-persistence.json)。缺少可控网络故障注入，因此“删除成功后资料读取失败”的恢复分支仅完成代码审查，未在浏览器注入故障复验。
