# 形象设计工作室开发验证

日期：2026-10-26。依据：[需求](../../02-需求文档/2026-10-26-形象设计工作室/01-需求说明.md)及[实施计划](../../02-需求文档/2026-10-26-形象设计工作室/02-实施计划.md)。本记录为开发临时验证，不作为真实供应商或生产验收。

## 实现与审查

创建页采用图片主导的双栏布局，将照片选择与上传归入同一入口，必穿单品在抽屉内分页选择；场合快捷选择、更多条件、个人偏好摘要和确认层形成连续流程。新增预览请求管理，限制例外修改后自动重核验，旧响应和关闭后的响应不再改变有效预览。

详情页沿用工作室布局，真实阶段、方案摘要、图片切换及单品穿法前置；完整设计依据折叠，重要限制与示意鞋提示保留在图片附近。现有任务路由、轮询、动作条件和幂等找回规则不变。

主 agent 核对了 Spec 覆盖、代码差异、状态隔离及实际页面。首轮截图发现全局图片样式覆盖局部高度，主图和缩略图尺寸不符合设计；实现 agent 提升局部选择器优先级并清除缩略图最小高度，浏览器复验通过。未修改后端、生成开关、依赖或数据库。

## 浏览器环境与结果

Playwright 驱动 Chromium 151.0.7922.34，访问现有 Vite `127.0.0.1:5173`，视口 1440×1000 和 1024×900，语言 zh-CN、时区 Asia/Shanghai。登录、照片、衣物、预览和任务请求使用浏览器隔离路由响应，图片带 TEST FIXTURE 标记，未使用真实账号数据或发起供应商调用。临时脚本位于 `/tmp/lookmate-studio-qa/`，没有新增长期 UI 测试框架。

| 场景 | 实际结果 |
| --- | --- |
| 创建页宽屏 | 主图实测高度 640px，object-fit 为 contain，照片与右侧操作清晰分栏 |
| 模式切换 | 保留手选或已选照片，发型模式隐藏必穿衣物，显示照片适用提示 |
| 选衣与分页 | 请求 page=2&pageSize=20，跨页保留所选；关闭抽屉后可在主页面移除 |
| 限制例外 | 自动发起包含新例外值的核验，期间生成按钮不可用，完成后恢复 |
| 关闭核验 | 延迟响应到达后不重开确认层、不自动生成 |
| 提交与刷新 | 更新任务链接，刷新恢复同一任务，完整观察期间只发送一次提交 |
| 各任务阶段 | 规划、生图、保存、失败、待确认、成功均显示相应状态，未使用虚构百分比 |
| 文字成功图片失败 | 文字可读，显示仅重试效果图入口，不允许完整方案收藏 |
| 原图与效果图 | 可切换且图片来源对应正确；必要限制在图片区旁可见 |
| 窄桌面 | 创建与结果上下排列，无横向溢出，内容可滚动阅读 |
| 能力不可用 | 预览拒绝原因显示，生成按钮不可用 |
| 无默认照片 | 引导添加，未选择照片前不可继续 |
| 照片库 | 选择已有照片后回到工作室 |
| 键盘与长内容 | 抽屉和确认层可用 Escape 关闭，焦点回到触发按钮；1350 字要求不撑破布局 |
| 提交响应不确定 | 保留恢复记录，刷新只找回原任务，没有再次提交 |
| 图片读取失败 | 重试后显示图片 |
| 文字评价与旧记录 | 无照片文字评价不提示等待生图；无图历史记录仍可阅读 |
