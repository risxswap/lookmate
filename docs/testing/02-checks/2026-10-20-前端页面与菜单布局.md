# 临时验证：前端页面与菜单布局

日期：2026-10-20。来源：[页面布局需求](../../02-需求文档/2026-10-20-前端页面与菜单布局/01-需求说明.md) 与 [实施计划](../../02-需求文档/2026-10-20-前端页面与菜单布局/02-实施计划.md)。本记录为开发阶段的局部验证，不属于真实业务流程验收。

## 环境与数据

前端地址 `http://127.0.0.1:5173`。使用 Playwright CLI 0.1.22 驱动真实浏览器，默认检查视口 1440 × 1000，另检查 1024px 桌面宽度。后端未运行；浏览器拦截 `/api/auth/me`，返回仅用于检查的 `layout_demo` 账号，不访问真实用户数据。模拟响应仅存在于本次浏览器会话，应用代码不包含认证绕过。

## 实际尝试

1. 本机直接运行 `npm run dev` 失败，原因是项目尚未安装依赖。直接 `npm ci` 因 Node 低于项目要求而失败，未修改依赖或 engines 规约。
2. 使用 `npm exec --yes --package=node@24.22.0 -c 'node --version && npm ci --no-audit --no-fund'` 按锁文件安装成功，Node 输出为 v24.22.0，随后启动开发服务。

3. 实页检查四个菜单、资料三个页签、收藏标签及查询参数刷新保留通过。记录模式可切换，衣橱选择“饰品”后选中状态与说明一致；未知私有路径显示未找到页面并可回到工作台。
4. 第一次三模式自动操作使用 `radio.check()`，因 Ant Design 的原生 radio 隐藏而超时，属于测试定位问题；改为点击实页可见 label 后，三模式切换、发型模式隐藏尺寸与必穿单品、公共输入保留和生成按钮禁用均通过。修正设计要求标签关联后，可按“设计要求”定位输入框。
5. 已查看工作台、收藏、资料与设计截图；1440px 与 1024px 下主要内容可读，1024px 设计页无横向溢出。页面未虚构照片、单品或任务结果。
6. 账号菜单能进入个人资料。模拟未认证时私有路径跳转登录，`returnTo` 保留 `/app/profile?tab=photos`。登录页不显示私有侧栏。
7. 退出检查初次失败：清空查询后账号重新查询，可能将 `lookmate:hadSession` 写回。本次使用持续返回成功的模拟账号响应重现，已增加跳转阶段保护并在跳转前再次清理。复验通过：模拟账号仍持续返回成功时，退出后标记为空；模拟退出 503 时页面保持会话并展示错误；随后未认证访问保留目标路径且不误报过期。
8. Node 24.22.0 下类型检查及 Vite 生产构建通过。构建仍提示单包超过 500 kB，未在本轮调整拆包。控制台检查未见应用警告或错误；模拟 401、503 的网络错误属于预期认证场景。

## 边界

本轮不验证真实身份认证、数据库保存、图片上传、识别、收藏或模型生成；页面不得显示这些操作已成功。未验证带数据的任务、结果详情、图片加载与异常状态；这些页面需要业务接口细化后继续实施。
