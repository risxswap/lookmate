使用 Java 21、项目 Maven Wrapper，测试数据库为独立 MySQL 库 `lookmate_design_delete_20261028_qa`，已应用现有全部迁移；Redis 使用独立 namespace。未修改共享开发库或生产。模型及对象存储使用测试替身，未调用真实供应商。

以下 Maven 命令在 `apps/server` 执行。集成命令额外设置 `LOOKMATE_INTEGRATION=true` 和指向隔离配置的 `SPRING_CONFIG_ADDITIONAL_LOCATION`，配置含凭据，不入仓库。

- `./mvnw spotless:check test -q`：通过；报告共 232 项，实际执行 121 项，跳过 111 项，无失败或错误。跳过项主要是需显式启用的集成和浏览器夹具。
- `./mvnw test -Dtest=DesignLifecycleIntegrationTest -q`：首轮 13 项通过，其中新增 3 项、继承既有生成回归 10 项。后续补充后，按方法筛选执行最终新增 5 项，全部通过。
- 最终 5 项方法：`deleteProtectsStateAndOwnershipAndPreservesFiles`、`hidingKeepsDeadlineAndPurgesOnlyAfterExpiry`、`deletionRollsBackAndRetainsIndependentReferences`、`confirmedHiddenTaskPurgesAndRetryRetainsItsSnapshot`、`mvcReturnsLifecycleContract`。
- `./mvnw spotless:apply spotless:check test -Dtest=OutfitIntegrationTest -q`：5 项全部通过，格式检查通过。

## 已验证行为

- 跨账号及活动状态删除被拒绝；确认失败可删除，任务引用随事务删除，文件未被同步物理删除。
- UNKNOWN 可隐藏，重复隐藏不延长截止时间，隐藏后详情不可读；期限前保留，七天期限到达后清理。
- 隐藏任务确认失败后可以清理；独立重试任务的输入快照、文件引用和来源编号快照保持不变，仅解除可空的来源记录关联。
- 删除成功任务时移除收藏及收藏夹归属。注入末尾删除失败后，独立数据库读取确认任务与收藏仍在，证明前序写入已回滚。
- 常用搭配的来源效果图指针纳入有效引用，不能因删除来源设计而清理；删除搭配时收集来源效果图安排后续清理。
- MockMvc 经真实 Spring Controller、Service 和隔离 MySQL 验证删除返回 200、空 data，以及状态冲突 409 和资源不存在 404。MockMvc 使用注入的已认证账号属性，未覆盖认证过滤链或真实 HTTP 网络。
