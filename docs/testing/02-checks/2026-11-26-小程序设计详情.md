# 小程序设计详情验证

2026-11-26，使用微信开发者工具、基础库 3.18.0 和独立本地工程，从「我的 → 设计记录」打开普通设计详情。测试账号的设计和图片由本地夹具提供。[需求与范围](../../02-需求文档/2026-11-20-小程序设计详情优化/01-需求说明.md#2026-11-26-从设计记录查看详情)

## 实际操作

| 场景 | 观察 |
| --- | --- |
| 打开整体设计 | 390px 屏幕上，成图完整显示为 354 × 472px，标题旁收藏和更多操作的点击区域高 44px。改前需要滚过成图才能看到这些操作。[改前详情](2026-11-26-小程序设计详情/01-改前详情.png) · [新版首屏](2026-11-26-小程序设计详情/02-设计详情.png) |
| 对照、收藏、保存 | 切到原照后在同页收藏，服务端替身返回更新后的收藏状态，页面仍显示原照。鞋子示意提示在原照下收起，切回成图后恢复。查看原照时打开「保存效果图到相册」，相册替身收到效果图文件。[页内对照](2026-11-26-小程序设计详情/03-原照对照.png) |
| 阅读方案、展开参考 | 穿法和发型打理建议默认显示。首屏没有请求参考图，展开「本次参考」后读取 3 张图片。再次展开没有新增请求，手动重试仅补读失败的 1 张。[方案建议](2026-11-26-小程序设计详情/04-穿搭与发型.png) |
| 放大当前原照与再次使用方案 | 从对照区点击原照，微信原生查看器打开第 2 张，显示「2/2」。点「调整后再设计」会带入同一张照片及设计要求。「存为常用搭配」发出一次创建请求，跳转到返回的搭配。 |
| 生成中与图片读取失败 | 活动发型任务显示出图阶段，已经写入的发型建议可读。模拟效果图读取失败后，点「重试图片」恢复图片，详情接口没有重复请求。[生成进度](2026-11-26-小程序设计详情/05-生成进度.png) |
| 无效果图与待确认任务 | 历史记录直接显示文字，点「看原照」进入单张原照大图。结果待确认时静置 4.3 秒没有自动查询，点刷新才发出一次查询。取消隐藏和取消重试均无写请求。有待确认提交时，点「找回任务」按原键查询并打开已有任务。 |

在 320px 模拟器上，长标题换成三行，占 292 × 95px。收藏与更多按钮留在标题上方，点击区域分别为 66 × 44px 和 44 × 44px。对照切换和原照预览可用，底部菜单最后一项完整可点。[窄屏长标题与坏图重试](2026-11-26-小程序设计详情/06-窄屏长标题.png)

## 构建与行为回归

小程序 173 项测试全部通过，其中详情页的 8 项覆盖原照对照、失败重试、刷新保持图像选择、参考图按需加载、任务轮询、权限和待确认提交。另验证了一张参考图重试期间另一张图渲染失败的情况，两张图分别保留各自状态。

构建检查通过 19 条路由、组件和本地图片引用。微信原生编译器通过 30 份 WXML/WXS 与 28 份 WXSS。此次使用已有详情与文件接口，真机显示、真实私有图片下载及系统相册权限待验证。
