## 检查安排

| 范围 | 预期与观察方式 |
| --- | --- |
| CRUD与分页 | 无照片和不完整组合可保存；详情可再次读取；页码/items/total相符，置顶先于非置顶；未知字段、非法值拒绝 |
| 版本与权限 | 他人搭配/分组/衣物/任务不可操作；版本冲突保留原值；提交键同输入重放、异输入冲突 |
| 分组与来源 | 同套多组；删除组仅解除关联；从设计保存后独立编辑；源衣物删除后提示缺失、图片可读取 |
| AI边界 | EVALUATION无本人照可成功且不调用生图；固定集合不增减；IMAGE要求本人照与基础衣物；历史结果revision准确 |
| 任务恢复 | 活动名额共用；UNKNOWN不重发；失败动作按服务端返回；旧revision完成不覆盖新组合 |
| 页面 | 工作台展示真实搭配，衣橱页内切换、创建编辑与分组、置顶、评价/出图、旧组合与缺失提示、刷新后持久化 |
