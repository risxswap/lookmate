# 小程序搭配详情布局验证

2026-11-26，在微信开发者工具 2.02.2608080、基础库 3.18.0 中，从衣橱切到「常用搭配」，分别打开已有上身图、手动组合和含已删除单品的搭配。隔离工程使用本地数据与照片，同一件搭配分别在 390px 的 iPhone 12/13 (Pro) 和 320px 的 iPhone 5 模拟器检查。[实施计划](../../02-需求文档/2026-11-18-小程序搭配详情优化/03-详情页布局实施计划.md)

| 操作 | 实际表现 |
| --- | --- |
| 查看已有上身图 | 使用 930 × 1240px 的全身照片，最终主图在 390px 屏宽为 356 × 474.7px，在 320px 为 272.2 × 362.9px。两种宽度均保留 3:4，画面可见头顶和鞋，图下有保存与重新生成入口。[390px 首屏](2026-11-26-小程序搭配详情布局/01-上身图.png) · [320px 首屏](2026-11-26-小程序搭配详情布局/02-窄屏上身图.png) |
| 打开手动搭配，查看衣物 | 长名称分两行，右侧保留编辑入口。三件拼图左侧为风衣，右侧为半裙和牛仔裤，下方单品条显示名称、颜色与分类。点拼图中的牛仔裤后，预览调用带入三件衣物的大图及牛仔裤的起始位置。[三件单品拼图](2026-11-26-小程序搭配详情布局/03-单品拼图.png) |
| 编辑及取消，打开照片选择 | 已保存的搭配可从名称旁进入编辑，取消后回到查看态。手动搭配可展开本人全身照、选择一张，再收起面板。有已删除衣物的搭配显示缺失提示，点禁用的生成按钮不会展开照片选择。 |
| 看笔记、安排和建议 | 「安排到日历」位于笔记下方，打开日历时带入当前搭配 ID。AI 建议先显示摘要，展开后可见搭配思路、配色和穿法。打开一条旧生成记录后，当前上身图地址保持不变。[笔记与建议](2026-11-26-小程序搭配详情布局/04-穿法笔记与建议.png) |

相同的 320px 测试图在初版容器中显示为 292 × 302.4px。调整图片比例后，已在两种宽度重新打开同一搭配核对。预览检查使用微信自动化替身记录传入的大图，未提交生成或日历写入。真机手势、系统相册保存及真实模型出图待验证。
