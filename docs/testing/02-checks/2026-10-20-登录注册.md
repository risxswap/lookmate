## 预期与实际尝试

1. 首轮构建发现 DurationMin 导入位置错误，修正后编译通过；前端类型检查及构建通过。
2. 通过 ops/Flyway 12.4.0 对本轮创建的空测试库执行原 V1，成功建表并写入原生迁移历史。应用只读兼容性检查通过。
3. 首轮 curl 检查发现数字密码被 JSON 转成字符串，实际返回 201，预期为 400。已增加严格文本转换配置和回归测试。保留 [首次失败记录](2026-10-20-登录注册/api-results-attempt1.json)。
4. 修复后复验并在最终后端版本再次运行，28 项检查通过，见 [接口响应](2026-10-20-登录注册/api-results.json)。覆盖匿名访问、缺少 CSRF、注册不自动登录、大小写唯一性、额外字段拒绝、数字及长度校验、密码空格、会话 ID 轮换、CSRF 轮换、两设备登录及独立退出、失败暂停、同 IP 请求额度。并发注册使用两个独立 curl 会话经屏障同时释放，返回 201 与 409。
5. 在独立测试配置中将空闲期限缩短到 3 秒、绝对期限到 8 秒、失败暂停到 3 秒，12 项检查通过，见 [期限响应](2026-10-20-登录注册/expiry-results.json)。持续轮询最终仍返回 401，暂停结束后正确凭据可登录，关闭注册返回 403。
6. Java 完整 verify 共 13 项、0 失败、0 跳过：4 项限流测试、4 项会话守卫测试、1 项 JSON 类型回归、3 项真实依赖启动、匿名权限及 Redis 命名空间检查、1 项 Redis 故障响应检查。默认 7 天边界使用固定时钟验证；不宣称实际等待 7 天。普通 verify 未开启集成环境时跳过那 4 项集成检查，不能将其记为通过。
7. Codex 内置浏览器观察到：确认密码不一致时停留表单并提示；注册成功到登录页，用户名预填、密码为空；登录后工作台显示测试账号；刷新保留登录；退出返回登录页；关闭注册隐藏表单；会话超期提示重新登录并保留 returnTo；限流显示递减等待秒数且禁用登录按钮。未采集确认密码失败期间的完整网络窗口，因此该项页面证据只证明可见校验行为。
8. 页面检查期间曾遇到标签失效及页面位置变化，重新定位后继续；某次构建覆盖正在运行的 JAR 导致类加载异常，改为独立运行副本后复验成功。发现 Ant Design Spin tip 弃用提示，改用 description；最终登录页控制台未见 warn/error。
9. 最终前端 npm run build 通过。产物主包约 750 kB，仍有超过 500 kB 的提示，未将其误写为零警告。

10. 补充 Redis 不可用场景时，首次返回 401 而非约定的 503。原因是 MVC 已选择响应输出流，异常出口又调用 Writer，导致二次异常。已改为完整重置响应并统一写输出流，新增真实 HTTP 回归测试通过；见 [首次故障](2026-10-20-登录注册/dependency-results-attempt1.json) 和 [修复后响应](2026-10-20-登录注册/dependency-results.json)。最终 Maven 为 12 项全通过，错误响应相关的 28 项 curl 检查再次通过。

11. 清理时发现旧配置 spring.session.redis.namespace 在 Boot 4 已失效。改用 spring.session.data.redis.namespace，新增真实 Redis 键与 Cookie 名称、HttpOnly/SameSite 检查。新隔离库与新前缀下再次执行接口验证；完整 Maven 13 项通过，追加 Cookie 断言后相关 3 项集成检查通过。此前默认前缀下有 1 个明确包含 Lookmate 登录时间属性的会话，已定向清理；另外 4 个无法确认归属的会话键保留原 TTL，未盲删。

## 结论与限制

后续版本决定：用户已将项目中间件基线改为本记录实际验证的 MySQL 8.0.45／Redis 7.4.11。下段所述原目标版本差异保留为测试当时的记录，不再作为当前待验证目标；生产相关限制继续有效。见 [版本调整](../../04-技术决策/2026-10-20-中间件版本对齐开发环境.md)。

本轮已观察的接口与页面行为符合模块需求。目标 MySQL 8.4 LTS／Redis 8.2.x、生产 HTTPS Cookie、可信代理来源 IP、生产 Compose 和 Nginx 回退规则尚未验证；既有开发库没有迁移。除登录注册外，其余表只验证了迁移执行，未验证业务行为或索引性能。

本轮未建立长期 UI 自动化，也不宣称正式验收或覆盖率。前端包体提示保留。数据库宕机后的完整恢复演练和生产服务容量验证留待部署与运维阶段。
