# 小程序衣橱首屏验证

2026-11-25，在微信开发者工具的 iPhone 12/13 (Pro) 和 iPhone 5 模拟器中，使用基础库 3.18.0 验证了本次构建。隔离项目使用本地测试账号，提供 5 件衣物、4 套搭配和 5 个分类。衣物图片取自已确认的交互稿，搭配来源图取自项目穿搭图库。[首屏需求及实施计划](../../02-需求文档/2026-11-13-小程序视觉优化/08-我的衣橱首屏实施计划.md)

| 操作 | 页面表现 |
| --- | --- |
| 打开衣橱 | 默认选中「衣物」和「全部」，显示 5 件衣物。390px 屏宽的首张方图为 172.5 × 172.5px，320px 为 140.5 × 140.5px。两种宽度下，「衣物」页签与「添加衣物」均在同一行，点击区高 44px。[390px 首屏](2026-11-25-小程序衣橱首屏/01-衣物.png) · [320px 首屏](2026-11-25-小程序衣橱首屏/04-窄屏衣物.png) |
| 选择「下装」，点牛仔裤，再返回 | 列表从 5 件缩小到百褶半裙、阔腿牛仔裤两件。点牛仔裤进入对应衣物详情，返回后「下装」仍选中，列表仍为两件。请求记录显示该分类从第一页读取，每页 20 件。[下装列表](2026-11-25-小程序衣橱首屏/02-下装.png) |
| 切至「鞋」后点「查看全部衣物」 | 空分类出现「这个分类还没有衣物」，点击后重新显示全部 5 件。点右上「添加衣物」进入新衣物表单。 |
| 切至「常用搭配」 | 共 4 套。第一套手动搭配的风衣与牛仔裤左右并排，保留「置顶」。带来源图的搭配只展示来源图。其余两套分别显示单张衣物图、无图占位。390px 屏宽的封面约为 172.5 × 230px，320px 约为 140.5 × 187.3px。[搭配封面](2026-11-25-小程序衣橱首屏/03-常用搭配.png) |
| 点「新建搭配」和「筛选与分组」 | 前者进入新搭配表单，后者进入管理页并显示夹具中的「通勤」分组。 |
| 320px 选择「上装」 | 没有照片的长名称衬衫显示「暂无图片」，名称在 140.5px 卡片中折成两行，高 45px。 |

本轮检查了页面渲染和导航。真实账号数据、微信真机交互、上传与保存未在本次模拟器验证中执行。
