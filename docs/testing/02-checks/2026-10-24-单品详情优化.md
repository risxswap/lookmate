日期：2026-10-24。依据：[需求](../../02-需求文档/2026-10-24-衣橱单品交互优化/01-需求说明.md#单品详情优化2026-10-24已确认已实现)与[实施计划](../../02-需求文档/2026-10-24-衣橱单品交互优化/02-实施计划.md)。

## 环境与范围

本轮为局部开发验证。使用 Codex 内置浏览器及本机构建产物，隔离 HTTP 夹具监听 127.0.0.1:5178；身份、单品、文件授权、保存及特征修订由夹具响应，图片为带 TEST IMAGE 标识的示意图，不读取或修改真实衣橱。临时服务脚本和请求日志位于忽略目录 `output/dress-detail/`。

## 实现复核

详情改为左右分栏，图片 ID 关联当前选择，资料与图片特征分区。特征默认收起，空值及空细节子字段过滤，人工值标识已修订；人工清空单独汇总。识别异常及旧结果过期提示位于折叠区外。编辑与特征修订复用原表单，嵌入同一个 Modal；编辑快照不被查询更新覆盖，保存继续等待查询刷新后返回详情。

浏览器发现主图与缩略图高度被全局同权重样式覆盖，已增强局部选择器并复验。另调整矮桌面主图高度，使 720px 高窗口完整显示缩略图；编辑切换恢复内容区焦点与滚动位置。

## 实际检查

| 场景 | 结果 |
| --- | --- |
| 1280×720、1000×720 | 左右布局可读，完整主图、缩略图及底部操作可见，未见横向溢出 |
| 默认进入详情 | 特征收起，UNKNOWN 提示和恢复操作可见；正常完成后变为轻量状态 |
| 展开特征 | 只展示有内容的字段，颜色标注已修订；细节只显示有值的领口，不展示空袖型 |
| 切换第二张 | 张数、主图、特征标题同步；空特征显示统一提示，旧结果过期提示在折叠区外 |
| 单品保存失败与重试 | 首次 PATCH 返回模拟 503，名称输入保留；重试成功回到详情，更新名称并保留第二张选择 |
| 取消编辑 | 修改名称后取消，详情仍显示已保存名称，请求日志没有取消草稿的 PATCH |
| 特征版本冲突 | 第二张图案填入“细条纹”，首次 PATCH 模拟 409；保存禁用，刷新版本后输入保留，使用新版本保存成功；返回第二张，显示细条纹和已修订 |
| 未知状态重试 | 显示额外调用提醒，确认后请求携带 recognitionId 和 confirmUnknown，返回后状态更新 |
| 同一弹窗与焦点 | 编辑态 DOM 中仅一个 dialog；切换编辑/详情后焦点进入当前内容区 |
| 删除确认与取消 | 更多菜单打开正文确认并恢复内容区焦点；取消后关闭确认，未发 DELETE |
| 当前图片被移除 | 夹具移除第二张后，通过更多→刷新单品，回退第一张并显示第 1/1 张 |
