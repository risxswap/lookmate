# 小程序基础资料与偏好临时验证

2026-11-19 核对已确认的头像、生日和资料分组交互。Node.js 24.22.0。微信开发者工具 Stable 2.02.2608080、基础库 3.18.0，视口为 390×844 和 320×568。[需求与验收](../../02-需求文档/2026-11-19-小程序基础资料与偏好优化/01-需求说明.md)

## 实际尝试

开发者工具服务端口关闭，CLI 未能启动隔离项目。随后通过图形界面导入游客项目，返回系统错误码 1。沿用工作区现有项目复验界面，选项和生日只改动模拟器草稿，写入由离线测试中的测试身份及接口替身验证。

| 场景 | 实际结果 |
| --- | --- |
| 390×844 打开编辑页 | 大图头像与更换入口位于页首，四组表单按顺序出现，底部有「保存资料」。 |
| 点击更换头像，取消系统选图 | 返回编辑页，保留当前头像和恢复默认入口。 |
| 选取生日并重开，取消，再清除 | 滚轮分别定位到已有和新选日期。清除后只显示「请选择」，清除按钮收起。从今天尝试向后选择一天时，确认结果仍为当天。 |
| 320×568 滚到「其他限制」，选择两项 | 长选项自然换行，两项均显示勾选，最后一个文本框能完整滚到保存栏上方。 |
| 离线检查头像与资料写入 | 确认裁切时上传裁切文件路径与实际字节数，再单独保存头像。取消、上传失败、账号切换均未提交头像变更。生日清除提交 `null`，保留其他资料。保存失败保留草稿，版本冲突需确认才重新加载。 |

`npm run build` 完成 TypeScript 检查、18 个页面及资源引用检查，`npm test` 通过 107 项。微信 `wcc` 编译 WXML 与 WXS，`wcsc` 编译页面与全局样式，均通过。

模拟器已恢复原机型，重新加载页面后显示原有资料。真机裁切界面、键盘弹出时的布局、真实七牛上传和服务端写入待验证。

## 单选和生日入口精简复验

同版本开发者工具的 390×844 模拟器中，性别、染发、烫发和日常打理投入均只显示实际选项。已有性别正确选中，改选时更新草稿。生日只显示日期和选择入口，已复验可打开年月日滚轮。空值提交、已有日期更新和选项改选由页面逻辑测试验证。

构建、原生编译及 108 项测试通过。

## 小程序内置头像裁切复验

使用同版开发者工具和一张本地生成的 720×960 测试图。在 390×844 模拟器从头像入口选图，画布居中铺满正方形，滑块从 100 调到 191 后取景放大，拖动可移动照片，取消返回资料页。首次检查发现画布盖住了样式绘制的圆形范围，改为由画布绘制。320×568 复验时圆形边线与暗角可见，滑块调到 222 后仍能拖动，两个操作按钮完整显示。取消后恢复原模拟器机型。

构建、原生编译及 110 项测试通过。页面逻辑测试验证确认前无导出和写入、导出时去掉预览线、仅按裁切图大小上传、失败后可重试，以及账号切换或离开后丢弃过期结果。模拟器操作止于取消，真实画布导出、上传、真机双指缩放及带相机方向信息的照片待验证。
