# 工作台开发验证

日期：2026-10-20。来源：[工作台需求](../../02-需求文档/2026-10-20-工作台/01-需求说明.md)。本记录为开发验证，不是正式回归报告。

## 环境与范围

当前工作区，Java 21.0.8、Node.js 24.14.0、MySQL 8.0.45、Redis 7.4.11。后端 18085、Vite 15185；Codex 内置 Chromium，页面截图宽度 1265。使用本轮新建隔离库和独立 Redis 前缀，V1 经 ops/Flyway 显式迁移，原开发库与共享配置未改动。

Node 实际版本低于项目要求的 24.22.0，未修改 engine；类型检查与构建在上述版本通过，24.22.0 本轮未复验。构建仍提示主包超过 500 kB。未部署生产。

查询业务尚无提交写入口，因此有记录场景使用隔离库夹具，经过真实 Mapper、服务、HTTP、登录会话和浏览器渲染；不表示 AI 生成或完整写入流程已通过验证。账号通过既有注册、登录 API 创建。没有使用真实个人资料或图片。

## 后端与 HTTP

- `apps/server`：Java 21 下 `./mvnw verify` 通过；设置 `LOOKMATE_INTEGRATION=true`、`SPRING_PROFILES_ACTIVE=dev` 及隔离配置后，29 项检查通过、0 跳过。其中新增工作台服务参数检查 12 项、真实数据库场景 4 项。
- 后补的事务连接失败 MVC 回归独立执行 1 项通过，映射为 503 SERVICE_UNAVAILABLE，不泄露连接错误内容。[构建摘要](2026-10-20-工作台/backend-summary.txt)。
- 数据库测试覆盖所有任务状态、最近六条上限、创建时间与 ID 排序、隐藏及跨账号过滤、方案和明细归属、UTC、字符串大 ID、公开字段白名单。
- 首轮集成测试在同一事务内修改夹具后被 MyBatis 一级缓存影响，已在测试修改夹具后清理缓存并复验。此为测试夹具问题；没有据此修改生产查询缓存策略。
- curl 经实际 HTTP 完成 14 项断言，均通过，响应均包含 no-store：[匿名和空态 2 项](2026-10-20-工作台/api-empty.json)、[记录与权限 11 项](2026-10-20-工作台/api-records.json)、[最终产物状态变化 1 项](2026-10-20-工作台/api-final.json)。覆盖匿名 401、空数据、大 ID、失败保留方案、隐藏与越权 404、不存在记录、非法 ID 400、活动转待确认。

## 页面观察

1. 真实登录后展示空工作台，[截图](2026-10-20-工作台/empty.png)。开始设计及资料入口沿用既有页面。
2. 夹具数据下展示活动任务和最近六条记录，成功、失败及待确认均可见；长 ID 在详情地址与页面保持完整。[最终工作台](2026-10-20-工作台/workspace-final.png)。
3. 查看方案详情，风格、场景、设计理由、配色、穿法及单品说明正确显示；图片服务未接入提示明确。[详情](2026-10-20-工作台/detail.png)。发型字段已由数据库集成测试验证，本轮浏览器未逐项检查发型栏目。
4. 失败任务仍显示已保存文字，并提示未完整成功，[失败详情](2026-10-20-工作台/failed-detail.png)。隐藏记录显示不可访问页面，[404](2026-10-20-工作台/not-found.png)。
5. CDP 捕获工作台请求时刻 435370.973601、435374.819496、435378.007805；完成一次请求后约 3 秒再次查询。将活动夹具转 UNKNOWN 后页面自动更新，随后 8 秒无工作台请求；成功详情另观察 8 秒无详情请求。
6. 在真实浏览器中临时模拟 document.visibilityState=hidden 并触发事件，8 秒无工作台请求；恢复原属性并触发事件后，2.5 秒预算内观察到立即请求。此项验证事件处理，不等同于操作系统切换标签的自然事件验证；临时覆盖已删除。
7. CDP 临时阻断目标 API，页面保留旧数据并提示刷新失败，[初次截图](2026-10-20-工作台/refresh-error.png)。首次用“重试”定位按钮未匹配 Ant Design 的“重 试”，同时活动轮询恢复后按钮消失；在终态详情再次执行，点击实际按钮恢复成功。随后补验首次加载失败和手动重试，也通过。最终网络错误文案已改为中文，阻断规则已清空。
8. 删除本轮专用会话后，在工作台点击刷新，跳转 `/login?returnTo=%2Fapp&expired=1`，显示登录过期提示，[截图](2026-10-20-工作台/session-expired.png)。

## 限制与清理

AI 执行、图片访问、提交与写操作不在本次实现范围；生产部署、并发快照专项、自然标签可见性切换及大数据查询性能未验证。构建与上述开发验证通过，不代表完整设计业务已交付。

本轮临时进程、浏览器标签、测试库、独立会话键及临时凭据文件在交付前清理；验证证据仅保留脱敏响应和测试页面截图。
