# 小程序设计详情临时验证

2026-11-20 按[需求说明](../../02-需求文档/2026-11-20-小程序设计详情优化/01-需求说明.md)核对工作区小程序。微信开发者工具使用基础库 3.18.0，iPhone 12/13 Pro 模拟器的可用窗口为 390×671 CSS 像素，通过 miniprogram-automator 0.13.0 操作。独立本地项目使用固定账号、方案和仓库示例图片。业务请求、预览参数、相册保存和二次确认结果由夹具捕获。

| 场景 | 实际结果 |
| --- | --- |
| 整体设计首屏与预览 | 标题和场合、风格正常显示，实测主图保持图片比例。点击效果图和「看原照」传给预览同一组图片，并定位对应图片。 |
| 收藏与更多操作 | 收藏成功后显示「已收藏」。取消确认不会发出删除收藏请求，确认后恢复收藏入口。更多菜单显示保存相册、调整后再设计和删除。触发相册保存后菜单关闭。 |
| 穿搭、发型与本次参考 | 整体设计的穿法及发型建议默认可读，理由和参考适配可以展开。发型方案只显示发型建议。另有参考时在正文下方显示参考图。 |
| 历史缺图与加载失败 | 缺图任务直接显示文字建议。模拟第一次效果图加载失败时仍显示方案，点击重试后恢复主图。 |
| 生成中、失败与待确认 | 生成中显示真实阶段和现有方案。失败原因及重试入口相邻。「仅重试效果图」以 `IMAGE_ONLY` 模式发起重试并前往任务页。结果待确认时跨过一个轮询周期仍未自动请求，点击刷新只查询一次。 |
| 保存、调整、删除与隐藏 | 保存为常用搭配后前往搭配详情。调整后再设计打开相应模式。取消删除保留记录，确认删除和确认隐藏各自发出对应请求并返回。 |

首轮检查发现长标题末行只剩一个字，更多菜单叠加了两次底部安全区。修正后截图显示标题分行较均衡，菜单留白缩短。尝试由自动化点击原生确认框时未收到回调，改为在隔离项目内模拟同意与取消结果并核对写入。原生预览手势、系统相册权限、真实七牛和真机待验证。
