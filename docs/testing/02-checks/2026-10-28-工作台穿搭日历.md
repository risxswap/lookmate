## 环境与隔离

- Java 21、项目锁定依赖，独立 MySQL 数据库 `lookmate_calendar_20261028_http`，显式执行 V1–V8；专项集成测试另用既有隔离测试设施。
- 独立 server `127.0.0.1:18092`、Vite `127.0.0.1:5191`，图片由 `127.0.0.1:19092` 的本地 MemoryStorage 提供。使用两个专用测试账号与合成色块图片，无真实照片或模型调用。
- HTTP 及浏览器请求经过真实应用接口、会话与数据库；存储供应商为可控替身，因此不据此宣称七牛或模型供应商已验证。
- 共享开发端口、共享数据库和生产未变更。代码依赖 V8，部署新 server 前需由 ops 显式迁移。

## 真实HTTP检查

[脱敏请求与响应](2026-10-28-工作台穿搭日历/http-results.json)记录23组成功检查：

- 两账号注册登录、CSRF、匿名401、跨账号列表隔离、引用/修改/删除拒绝。
- 场景服务端分页、标签去重与revision不变、场景精确筛选和分页。
- 创建计划、只记场景待选衣、同键同载荷幂等、同键不同载荷409。
- 当天分页、周历数量、日期范围及非法分页、创建/修改未知字段拒绝。
- 仅修改备注不刷新搭配快照、旧版本409、显式同搭配替换刷新快照。
- 删除来源搭配和衣物后仍保留计划与快照，缺失标记正确，图片可继续授权。
- 删除计划后列表数量更新。

浏览器并发检查时追加了真实查询和修改请求，用于提高同一条安排的版本。追加请求第一次受沙箱本地网络限制连接失败，原始记录保留exitCode=7；获批重跑成功，不计入产品失败或额外业务通过项。临时curl脚本、cookie和测试凭据位于权限受限的 `/tmp/lookmate-calendar-verification`，未提交到仓库。

## 真实浏览器检查

使用内置浏览器、1280×720视口连接上述真实后端；最终文档横向宽度1265px，无横向溢出。依次验证：

1. 登录并打开正式工作台；一天6条安排按5条分页，切换第二页显示剩余记录；场景搭配及选衣窗口按4条分页。
2. 删除来源搭配和衣物后的历史安排仍可打开，显示原穿法、单品及缺失提示；[快照截图](2026-10-28-工作台穿搭日历/snapshot-retained.png)。
3. 选择10月29日，自定义“生日聚餐”，跨页选择“轻松通勤”并保存；整页刷新后重新选择该日仍存在。
4. 修改备注成功，界面继续显示保留安排时的组合与穿法。
5. 编辑窗口打开后通过HTTP模拟另一个窗口修改；旧窗口提交显示版本冲突并保留输入，关闭刷新后显示最新内容；[冲突截图](2026-10-28-工作台穿搭日历/version-conflict.png)。
6. 打开移除确认，核对日期、场景和仅移除计划的说明，再取消；实际删除由HTTP检查覆盖。
7. “旅行”筛选仅展示对应搭配；为“周末出游”增加“生日聚餐”标签并保存，按新场景筛选可以查到该搭配。标签下拉展开时，先点表单说明收起后再保存。
8. 从月历选10月30日，回到周历对应日期；“今天”回到当前日期。
9. 最终首页不显示返回按钮，任务与最近设计为空时保持紧凑布局；[正式页面截图](2026-10-28-工作台穿搭日历/workspace-desktop.png)。

收尾日志仅见Ant Design Modal的`maskClosable`弃用提示，未影响上述操作。构建的大包提示和组件弃用提示不是本轮阻塞项。

## 复核与限制

主agent检查了两端契约、非搭配编辑字段、账号隔离、user与资产锁顺序、快照保存及文件清理引用。发现并修复自定义场景与内部保留值冲突、快照详情入口缺失、首页返回按钮三个问题，前端最终重新构建通过。

未覆盖：其他桌面宽度、网络断开/超时后恢复的浏览器路径、有活动任务及非空最近记录的页面状态、浏览器完整替换与删除提交。既有任务轮询与actions组件继续复用，代码已复核，但不把复用等同于本轮浏览器验证。正式共享环境迁移、真实存储/模型供应商及生产部署未执行。

本轮保留隔离数据库和测试资料用于问题复现；独立HTTP、存储与Vite进程在验证结束后停止，共享服务不受影响。
