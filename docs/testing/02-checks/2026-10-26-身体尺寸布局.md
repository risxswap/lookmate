# 身体尺寸布局开发验证

日期：2026-10-26。范围为三栏编辑器及其分组、焦点交互；保存接口和正式历史弹窗不在本记录的已验证范围。

## 实现

左侧分组、中间人体两侧输入、右侧指南；移除正式页面和预览中将指南降到下方的旧容器覆盖。编辑器使用自身容器宽度适配。分组计数包含背宽及后腰节长；组内最后选中字段和正背面随分组切换保留。人体组和头脚组均按从上到下、每行从左到右的 DOM 顺序输入。问号仍可点击；键盘聚焦输入直接显示说明，Tab 不必经过问号。

## 实际检查

- `npm run build --prefix apps/web`：通过 TypeScript 与 Vite 构建，最终使用 bundled Node 24.22.1 复验通过；保留原有大包体积提示，无新增依赖。
- 使用 CUA 真实浏览器访问本地 `/profile-preview.html`，使用虚构尺寸，不写入服务端。
- 1024×768、1280×800、1440×900：三栏同排，无页面横向溢出；人体、手臂、腿部和头脚局部图可见。底部按钮仍可滚动访问。
- 补充 900×768 的预览窗口：编辑器实际宽 665px，指南保持右侧，人体输入可读，无横向溢出；这项检查用于较窄容器，不声明正式页面已通过。
- 身高填 165 后，Tab 依次到胸围、腰围，右侧说明同步；字段矩形每行同高，先左后右。头脚组左脚长后 Tab 到右脚长，图示同步。
- 背宽填 35 后躯干计数为 1/10；选中后腰节长，切到手臂再返回躯干，保留背面和后腰节长，焦点仍留在分组按钮。
- 依次填写身高、背宽、左脚长、臂长、内腿长后，总填写数为 5；切换男性后数值和当前指南保留。
