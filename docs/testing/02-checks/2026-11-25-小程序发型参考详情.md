## 主图收藏与「用这款发型」

| 操作 | 微信模拟器结果 |
| --- | --- |
| 点击主图右上角的空心心形 | 心形变为实心，收到一次收藏请求，仍停在详情。390px 窗口内心形的点击区域为 44×44px。[未收藏](2026-11-25-小程序发型参考详情/04-主图收藏入口.png) · [已收藏](2026-11-25-小程序发型参考详情/05-已收藏发型.png) |
| 收藏后切到侧面，点心形取消，再点主图 | 侧面图上仍为实心。取消后恢复空心，操作对应同一款发型。点击侧面主图后打开该角度的大图。 |
| 点击底部「用这款发型」 | 390px 窗口内，底部只有一个 354×44px 按钮。创建页收到发型类型、清爽短碎发的参考 ID 和版本 v2。 |
| 打开无图或已下架的参考 | 无图时可以从占位区右上角收藏。已下架时主按钮禁用，点击后停在详情。 |
| 切到穿搭，再打开参考 | 底部显示「收藏参考」和「使用此参考」，点击后者进入带该穿搭参考的创建页。 |

在 320px 窗口复验，底部按钮为 290×44px。心形点击区域仍为 44×44px，切换侧面后位置相同，收藏与取消各触发一次对应请求。本次 149 项小程序测试、构建及微信原生模板、样式编译均通过。

## 三视图首轮验收（调整底部按钮前）

| 操作 | 结果 |
| --- | --- |
| 在 390px 模拟器打开三图发型 | 默认正面主图约 280×280px，右侧缩图约 64×64px。标题下显示发长、刘海与质感；主图下能直接读到造型介绍和日常打理。底部两个按钮均高 44px。[正面首屏](2026-11-25-小程序发型参考详情/01-发型详情.png) |
| 点侧面、背面，再回到正面 | 主图和选中边框按对应角度切换，未新增图片请求。[侧面视角](2026-11-25-小程序发型参考详情/02-侧面视角.png) |
| 从侧面点主图，再左滑并关闭大图 | 微信原生预览从侧面（2/3）打开，左滑可查看背面（3/3）。关闭预览后，详情保留先前选中的侧面。 |
| 收藏后点「使用此参考」 | 收藏状态更新。创建页收到发型类型、清爽短碎发的参考 ID 和版本 v2。 |
| 打开缺正面、单图及无图的参考 | 正面缺失时主图展示侧面。仅有一张可用图时收起角度栏。无图时显示占位，名称、说明和打理建议仍可阅读。 |
| 让侧面图读取失败，再重试 | 其余角度仍可查看，重试仅请求失败的展示图。 |
| 切到穿搭图库并打开参考 | 穿搭详情仍显示单张全身图、配色、轮廓及穿着建议。 |

在 iPhone 5 模拟器（可用窗口 320×456px）中，主图约 228×228px，右侧缩图约 52×52px，两列相隔 10px。底部操作可以点击，正文独立滚动。延迟收藏响应后点关闭，响应返回时仍停在图库，列表中的收藏状态随之更新。[窄屏详情](2026-11-25-小程序发型参考详情/03-窄屏详情.png)
