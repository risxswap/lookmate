# 修改密码开发验证

日期：2026-10-21。依据 [需求与契约](../../02-需求文档/2026-10-21-修改密码/01-需求说明.md) 和当前未提交代码；本记录属于开发验证，不是生产验收。

## 环境与范围

Java 21.0.8、Node.js 24.22.0，沿用现有 MySQL/Redis 连接并新建独立数据库、独立会话前缀。Flyway V1 在本轮隔离库执行成功，共享开发配置和既有数据库不修改。后端 18082、前端 15174，仅绑定本机回环地址；临时凭据文件权限为 600，凭据不进入证据。

预期检查正确修改、旧密码不能登录、新密码可以登录、两个旧会话失效、密码边界与严格字段、原密码错误、CSRF、限流及并发单赢家。页面检查个人资料入口、表单必填提示、取消和重新打开；修改成功的业务结果通过 HTTP 和数据库集成检查。

## 实际尝试

- 前端使用 Node.js 24.22.0 执行 `npm run build`，类型检查与构建通过；保留既有主包超过 500 kB 提示。
- 后端首轮新增并发集成测试的 Mockito 夹具试图对 MyBatis 接口使用 callRealMethod，测试夹具报错。改为先读取真实数据库快照、使用屏障控制并发，实际写入仍通过真实 MySQL 条件更新；最终完整复验通过。

- Java 21 下，在 apps/server 执行 `LOOKMATE_INTEGRATION=true SPRING_CONFIG_IMPORT=file:/临时配置 ./mvnw verify`，84 项测试通过，0 失败、0 错误、0 跳过。含新增 5 项单元测试与 3 项真实 MySQL 集成测试，覆盖指纹绑定、两设备失效、并发单赢家、原哈希精确比较及资料版本不变。脱敏统计见 [后端测试](2026-10-21-修改密码/backend-tests.json)。
- curl 首次执行 23 项、22 项符合预期；修改成功销毁会话后，辅助脚本没有重新取得 CSRF 就尝试登录，返回 403。此为脚本凭证处理错误，已保留 [首次尝试](2026-10-21-修改密码/http-first-attempt.json)。补充 CSRF 获取后，使用新账号重新执行 [35 项检查](2026-10-21-修改密码/http-results.json)，全部通过，未修改产品代码或放宽业务断言。
- Codex 内置浏览器在 1280×720 桌面视口，登录隔离账号并打开个人资料基础资料页。修改密码弹窗展示原密码、新密码、确认新密码和所有设备退出提示；空表单提交出现三个必填提示，取消后重新打开错误提示清除。见 [最终弹窗](2026-10-21-修改密码/password-form.jpg) 与 [必填提示](2026-10-21-修改密码/password-required.jpg)。
- 页面首次打开发现 Ant Design `maskClosable` 弃用警告，改为 `mask.closable` 后重新构建通过，再次登录打开弹窗没有新增该警告。
- 通过另一 HTTP 会话修改同一隔离账号密码后，刷新浏览器自动进入登录页并提示会话过期；使用更新后的密码在浏览器重新登录成功并回到资料页。见 [辅助接口结果](2026-10-21-修改密码/browser-support-http.json) 与 [旧页面失效](2026-10-21-修改密码/password-session-expired.jpg)。此步骤没有通过浏览器提交修改密码表单。

## 验证限制

浏览器工具规定修改认证凭据须由用户接管，不能自动输入新密码并提交。为避免要求用户操作一次性测试账号，本轮浏览器仅检查入口、空表单校验和取消；修改、双设备失效及重新登录通过 curl 验证。浏览器端实际填写新密码后成功跳转、错误密码提示和限流倒计时尚未运行验证。
