# 临时验证：小程序个人照片卡片

2026-11-19。依据[个人照片卡片操作](../../02-需求文档/2026-10-30-微信小程序/01-需求说明.md#个人照片卡片操作)。微信开发者工具 Stable 2.02.2608080，基础库 3.18.0，模拟机型为 iPhone 12/13 (Pro)（390×844）和 iPhone 5（320×568）。

| 尝试 | 实际结果 |
| --- | --- |
| 启动本地游客项目，准备有图和空位夹具 | CLI 的服务端口关闭。图形界面导入游客项目返回「系统错误，错误码：1」。 |
| 在已打开的项目进入「我的 → 个人照片」 | 当前六个照片位均有图。两种宽度下照片保持双列，标题和「···」同行，图下无独立操作按钮。 |
| 点击正面头像照 | 模拟器打开单张原图预览。 |
| 点击右上角「···」 | 两种宽度下均显示「更换照片」「删除照片」「取消」。选择删除后出现二次确认，取消后照片和预览入口仍在。 |
| 运行离线页面逻辑测试 | 核对了空位添加、补充照片替换、删除确认的目标和请求参数、菜单及确认框取消时无写入，以及缩略图失败后仍可请求原图。 |

Node.js 24.22.0 下，`npm test` 通过 111 项，`npm run build` 通过。微信 `wcc` 编译 28 份 WXML/WXS，`wcsc` 编译 26 份 WXSS，均成功。

模拟器已恢复原机型，停在个人照片页。空位实际渲染、真机选图、实际上传和真实删除待验证。本次使用现有照片只读复验，未对共享环境写入照片数据。
