# 小程序我的收藏临时验证

2026-11-20 核对[本轮需求](../../02-需求文档/2026-11-20-小程序我的收藏优化/01-需求说明.md)。使用微信开发者工具 Stable 2.02.2608080、基础库 3.18.0 和 iPhone 5 的 320×568 视口。独立项目加载工作区构建产物，以本地测试账号和固定数据替代用户请求。封面使用仓库现有样图，另模拟一个文件 ID 缺失和一个缩图请求失败。

| 操作 | 观察结果 |
| --- | --- |
| 打开全部收藏 | 首屏显示筛选、管理和两列竖版效果图。长收藏夹名截断，长方案名换行，类别与详情入口可辨认。两项不可用封面正常显示占位。 |
| 点击卡片及单条更多菜单 | 点击卡片进入设计详情，返回重读收藏。更多菜单在底部打开，提供调整收藏夹和取消收藏。初次验证发现按钮落在卡片左下，改由原生容器定位后，复验按钮在右侧且少占一行。 |
| 调整两个收藏夹中的同一方案 | 取消「通勤」勾选后「周末」仍为已加入。切到「周末」并移出该收藏，列表总数从 1 变为 0，显示空夹提示。 |
| 在管理面板创建、改名并删除测试夹 | 新建和改名成功后更新夹名。删除确认说明其中收藏会保留，确认后该夹消失，收藏总数仍为 22。 |
| 触底后模拟第二页失败 | 保留首批 20 张卡片及服务端总数 22。错误区出现后继续滑到底，点击「重试加载」再次请求第 2 页，补齐至 22 张卡片，错误消失。 |

测试号目录导入返回系统错误码 1，使用同一工作区 AppID 导入另一份本地文件，业务请求与会话均在替身中处理。尝试切换 390×844 时开发者工具重启，未完成该尺寸复核。测试项目窗口在重启后关闭，测试写入只作用于运行时内存。真机、线上后端与真实七牛缩图请求待验证。

- 小程序 `npm test` 通过 123 项，新增 6 项收藏回归覆盖封面降级、分页重试、筛选切换、收藏夹分页、版本冲突、取消确认、归属变更及账号隔离。`npm run build` 通过，共 19 条页面路由。微信 `wcc` 和 `wcsc` 分别编译 29 份模板及脚本和 27 份样式，通过。
- 后端 `./mvnw -B verify` 通过 182 项，有 153 项受环境变量控制而跳过。新建隔离 MySQL 8.0.45 数据库及 Redis 实例后，定向 `RecordsIntegrationTest` 9 项全部通过，核对 GET／PUT 实际响应、超出 JavaScript 安全整数范围的文件 ID、缺图、非本人图片引用和收藏夹分页。隔离实例已关闭。
- Web 构建通过，Vite 提示存在大于 500 kB 的分块。`git diff --check` 通过。
