# 小程序添加衣物表单验证

2026-11-25 至 26 日，在微信开发者工具 2.02.2608080、基础库 3.18.0 中检查新增和编辑衣物。两个隔离场景分别使用 iPhone 12/13 (Pro) 的 390px 屏宽和 iPhone 5 的 320px 屏宽。测试工程复用了本轮小程序构建，衣物数据、选图结果、上传响应与保存响应由本地夹具提供。[实施计划](../../02-需求文档/2026-11-13-小程序视觉优化/09-添加衣物表单实施计划.md)

| 操作 | 观察结果 |
| --- | --- |
| 从衣橱点「添加衣物」 | 标题显示「添加衣物」，照片区位于名称和分类之前，初始张数为 0 / 8。390px、320px 下添加区分别宽 356px、292px。保存按钮与内容等宽，高 48px。[390px 新增首屏](2026-11-25-小程序添加衣物/01-新增衣物.png) · [320px 新增首屏](2026-11-25-小程序添加衣物/02-窄屏新增衣物.png) |
| 空表单点保存，再填写名称和分类 | 照片、名称、分类各自显示缺项提示。填写「测试风衣」并选择「外套」后再点保存，只剩照片提示，输入仍在。[必填项提示](2026-11-25-小程序添加衣物/03-必填项提示.png) |
| 选择季节、填写备注、添加一张照片后保存 | 春和冬可同时选中。点照片入口后，测试替身返回衣物照片。表单提交名称、分类、两项季节、备注与一张图片，收到隔离服务返回的衣物 ID 后留在详情页。两种宽度下四季均在一行，每项高 44px。滚到底后保存按钮位置不变，备注和删除入口都可完整显示在按钮上方。 |
| 打开已有多图衣物和满 8 张照片的衣物 | 详情页显示已保存名称、分类和季节。三张照片可横向滚动；从第二张的更多操作选择设为封面后，它移到第一位。点新封面会为该照片请求预览地址。8 张时页面收起添加入口。[已有衣物](2026-11-25-小程序添加衣物/04-已有衣物.png) |
| 在 320px 模拟器注入一次分类读取失败 | 页面只显示错误和「重新加载」，点重试后照片、表单和保存按钮恢复。 |

分类选择使用原生选择器的 change 事件。照片菜单和大图调用使用微信自动化测试替身；本轮核对了菜单选择结果、页面内的封面顺序与预览取图请求。真机键盘、系统相机与相册、七牛上传、真实账号写入及原生大图手势待验证。
