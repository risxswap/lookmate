## 按钮说明与图库空状态

在同版本微信开发者工具中打开工作区项目，用 390×844 模拟器复验。切到「整体」后，「同时设计发型和穿搭」居中显示在「开始整体设计」按钮下方。发型参考切到「仅收藏」时显示「还没有收藏的参考」，并提示如何返回完整图库。再次点击后恢复 48 个参考的列表总数。

`npm run build` 通过，`npm test` 共 97 项通过。真机与其他空状态组合待验证。
