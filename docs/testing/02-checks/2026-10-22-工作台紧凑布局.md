## 实际结果

- 1440×960正常首页：页头仅标题和开始形象设计主按钮；搭配区无解释文字、分组管理或刷新；四张卡片可直接浏览，下方直接接最近设计，无空活动任务或常驻准备卡。
- 更多菜单取消置顶成功，卡片顺序和置顶标记更新；分组选择周末后仅显示周末散步。
- 有活动任务且缺照片/衣物：任务卡正常展示，准备区只有简短文字和对应链接。
- 资源查询503：显示读取失败与重试，无缺少照片/衣物的错误提示；恢复夹具后点击重试可恢复。搭配及最近设计为空时不重复主操作按钮。
- 查看全部进入衣橱常用搭配标签，管理分组、刷新及直接置顶仍可见。
- 1100×800桌面：标题和操作可读，卡片两列；documentElement的scrollWidth与clientWidth均为1085，无横向溢出。
- Node24.22 `npm run build`（含typecheck）通过，保留既有大包警告；git diff --check通过。本次没有后端改动，未重复运行数据库集成测试。
