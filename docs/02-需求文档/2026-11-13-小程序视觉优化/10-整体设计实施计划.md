## 填写页优化

入口为 `pages/design-create/index?mode=OVERALL`。沿用暖白底色、墨绿操作色、TDesign 按钮与弹层，使用本人的真实照片和衣物缩图。[本次范围](01-需求说明.md#点击开始设计后的填写页)

- [x] T4 照片与造型要求。修改 `pages/design-create/index.{ts,wxml,wxss}` 与 `tests/design-create.test.mjs`。选中的照片以紧凑的 3:4 缩图和名称展示，点击更换后展开候选区。未选照或收到换照错误时可直接选图。将常用场景与风格分别做成可取消的单选项，并提供自定义文字输入。用已有草稿回填，逐项核对快捷选择、自定义、换照和预检请求。
- [x] T5 搭配衣物。T4 完成后在同一页调整衣物区域与测试。主表单显示自动搭配或已选衣物摘要。「从衣橱选」打开可独立滚动的底部面板，按服务端分页加载。点「完成选择」才将暂选衣物写入草稿，取消或轻触遮罩放弃本次调整。测试覆盖跨页、重试、取消与确认，检查衣橱列表只在需要时读取。
- [x] T5 分页刷新。面板内触底追加下一页，下拉刷新第一页，刷新失败后保留当前列表和暂选衣物，可重试同一页。
- [x] T4 补充检查。收起照片区后只读取当前选照的缩图地址。首次展开时补齐候选，重复展开复用当前页面已读的照片。通过 `/files/{id}/access` 的请求记录核对首屏、切换及失败后重试。
- [x] T6 模拟器与交付。在 `apps/miniapp` 运行 `npm test`、`npm run build` 及微信原生编译。在 320px 和 390px 的隔离模拟器检查已选照首屏、更换照片、场景与风格自定义、选衣面板及确认单，核对返回修改、确认前零提交和最终提交内容。保存本轮截图并更新功能总览。
