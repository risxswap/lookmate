# 添加衣物表单实施计划

2026-11-25，用户要求优化微信小程序添加衣物页。新增和编辑共用表单，沿用现有服务端字段、保存语义、照片和识别菜单。[需求说明](01-需求说明.md#2026-11-25-添加衣物表单)

- [x] T1 表单与布局。修改 `apps/miniapp/src/pages/dress-edit/index.wxml`、`index.wxss` 和原生导航配置 `index.json`。设计紧凑的空照片上传区，已有图片保留原生横滑、封面标识与独立菜单；显示张数，8 张时收起添加。名称和分类靠前，选填资料单独分区，四季保持同排可多选。底部固定通栏保存，预留安全区、末尾内容和删除入口空间；识别面板打开时收起固定操作。使用真实表单控件、既有本地图标与主题。
- [x] T2 表单反馈。修改同页 `index.ts`，在小程序测试中补充相应回归场景。新增显示「添加衣物」，编辑及首次保存成功后显示「衣物详情」。上传前按剩余名额限制选图；缺照片、名称或分类时在相应字段提示，保留草稿。保存、上传及后台识别仍用现有接口。视图使用 `fieldErrors.photos/name/category`（字符串）、`saving`（布尔）、`loadFailed`（布尔，仅初始化读取失败时提供重新加载）；三个校验区 ID 为 `dress-photos`、`dress-name`、`dress-category`。保留编辑锁和原生季节复选组。
- [x] T3 验证。合入 T1、T2 后，在 `apps/miniapp` 执行 `npm test`、`npm run build` 及微信原生模板和样式编译。使用隔离数据在 320px、390px 微信模拟器检查空表单、必填提示、保存按钮位置、季节单行和已有衣物的照片与编辑操作。记录实际覆盖的操作、截图及真机缺口，更新需求和功能总览。
