## 任务 2 创建设计

文件为 `apps/miniapp/src/pages/design-create/index.{wxml,wxss,ts,json}`。需要回归测试时放在 `apps/miniapp/tests/design-create.test.mjs`。与任务 1 使用原模式和参考 ID、版本参数，可并行实施。

- [x] 根据模式设置原生标题。顶部为可横滑的照片区和管理入口。已选参考显示缩图、名称及移除入口，发色开关移入「更多设置」。素材无法查看时保留占位、预检和移除入口。
- [x] 场景、风格紧随「你的想法」，默认可见并恢复草稿。样图的示例值只用作占位。天气和尺寸收进「更多设置」。穿搭和整体显示可收起的必穿衣物选择区，保留服务端分页、已选摘要及失败重试。
- [x] 底部固定「检查并继续」。预检通过后打开确认单，关闭时保留输入，点击「确认生成」才提交。冲突处理、输入变更后重查、令牌时效、提交失败及原键恢复按现有规则执行。
- [x] 新增 5 项页面逻辑测试，覆盖确认取消及重复点击、冲突后重检、原键恢复、预检过期、衣物分页重试、照片缺失及参考加载失败。
