# 登录注册

创建日期：2026-10-20。最后更新：2026-10-20。

状态：表单、跳转、失败限制和会话体验已确认，前后端已实现并完成本轮开发验证。中间件版本已统一为验证所用的 MySQL 8.0.45／Redis 7.4.11，生产部署尚未实施。

## 目标与范围

完成用户注册、登录、退出、登录状态恢复及页面访问控制，覆盖 server 和桌面端 web。登录后先提供工作台入口，后续业务模块逐步接入。

账号唯一性、会话期限、多设备登录及权限沿用 [领域模型](../../01-项目总览/02-领域模型.md#账号与个人资料)。不包含手机号、第三方登录、找回密码、记住我和设备管理；显示名称编辑属于个人资料模块。

## 已确认的表单与跳转行为

- 注册页填写用户名、密码和确认密码；显示名称留到个人资料设置。
- 用户名为 4～32 位英文字母、数字或下划线，忽略大小写，全局唯一。
- 密码为 8～64 位，允许字母、数字、符号和空格，不强制字符组合，不自动删除首尾空格。按 Unicode 码点计数。
- 确认密码只在前端校验，两次一致才提交，不作为后端请求字段。
- 注册成功后跳转登录页并预填用户名，不保留密码，不自动登录。
- 注册关闭时隐藏注册入口；直接访问注册页显示“暂未开放注册”。后端仍须独立检查注册开关。
- 登录成功返回此前访问的站内页面；没有目标页面时进入工作台。
- 登录失败统一提示“用户名或密码错误”。

## 契约影响

沿用 [接口契约](../../01-项目总览/05-接口契约.md#认证与资料) 的公共响应、Cookie 会话和 CSRF 约定。注册请求为 username、password，拒绝 displayName 等额外字段。具体请求响应、错误和限制见下文实施约定。

## 验收条件

以下行为已纳入本轮验证，实际证据与环境限制见验证记录：

- 用户名大小写不同的重复注册被拒绝；非法用户名与超出密码长度范围的输入被拒绝。
- 密码首尾空格保持原值；确认密码不一致时前端不提交。
- 注册成功进入登录页，用户名预填，密码清空，未建立登录身份。
- 注册关闭后，入口隐藏、注册页有明确提示、注册请求被后端拒绝。
- 登录失败不区分账号不存在与密码错误；成功后回到此前站内页面或工作台。
- 刷新页面可恢复有效登录状态；会话期限和退出仅影响当前会话的行为按既有约定验证。

## 失败限制与会话体验（已确认）

- 同一来源 IP＋小写用户名在 15 分钟内失败 5 次，从第 5 次失败起暂停该组合登录 15 分钟；成功登录清除该组合的失败计数。
- 同一 IP 每分钟最多提交 30 次登录请求，每小时最多提交 10 次注册请求。采用从首个请求起算的固定窗口；格式错误也计入请求额度。
- 触发限制返回剩余等待秒数；不永久锁定账号，不影响已有会话。阈值、窗口和容量可配置。
- 首版使用有容量上限的服务端内存计数，服务重启后重置；Redis 仍只保存会话。容量耗尽时拒绝新增计数项，不淘汰仍有效的限制来放行请求。
- 会话过期提示“登录已过期，请重新登录”，停止私有数据请求，重新登录返回原站内页面。
- 退出成功后进入登录页，清空用户数据与查询缓存。

## 接口实施约定

响应沿用 data/requestId 与 code/message/requestId。ID 为字符串，密码按 Unicode 码点计数，前后端一致；不裁剪或规范化密码。用户名不裁剪，校验后转小写。注册开关默认关闭，开发环境显式开启。

| 方法与路径 | 请求 | 成功响应的 data |
| --- | --- | --- |
| GET /api/auth/config | 匿名 | {registrationEnabled: boolean} |
| GET /api/auth/csrf | 匿名或登录 | {token: string, headerName: string} |
| POST /api/auth/register | username、password，均必填字符串且非 null；拒绝其他字段 | 201，{id: string, username: string, displayName: null} |
| POST /api/auth/login | 同注册字段 | 200，{id: string, username: string, displayName: string或null}，轮换会话 ID |
| GET /api/auth/me | 登录 | 200，同账号摘要 |
| POST /api/auth/logout | CSRF 请求头，无请求体 | 200，null，销毁当前会话 |

所有 POST 都验证 CSRF；登录、退出后重新获取 token。账号停用或不存在按无效凭据处理；已有会话每次请求检查账号有效性。服务端检查从登录起算的绝对期限，不依赖 Redis 空闲 TTL。退出时已有会话失效也按成功清理处理，但仍验证 CSRF。

| HTTP / code | 前端行为 |
| --- | --- |
| 400 / VALIDATION_ERROR | 展示 fieldErrors 或安全错误提示，保留当前输入 |
| 401 / INVALID_CREDENTIALS | 显示用户名或密码错误，不作为全局会话过期跳转 |
| 401 / UNAUTHENTICATED | 私有页面进入登录流程；初次匿名访问不显示过期警告 |
| 403 / REGISTRATION_CLOSED | 隐藏注册表单，提示暂未开放注册 |
| 403 / CSRF_INVALID | 获取新 token，提示重试；不自动重发写请求 |
| 409 / USERNAME_TAKEN | 提示用户名已被使用 |
| 429 / RATE_LIMITED | 使用 retryAfterSeconds 和 Retry-After 展示倒计时 |
| 503 / SERVICE_UNAVAILABLE | 提示服务暂不可用，不冒充凭据错误或清空有效会话 |
| 500 / INTERNAL_ERROR | 提示请求未完成，附 requestId 供排查 |

登录请求限流在读取 JSON 前执行，失败组合限流在密码比对前后分别校验和计数。来源 IP 使用连接地址，不直接信任客户端传入的转发头；生产代理须按可信代理配置接入。会话 Cookie 为 HttpOnly、SameSite=Lax，生产 Secure，开发 HTTP 显式关闭 Secure。认证响应禁止缓存，密码、哈希、Cookie 和 CSRF 不进入日志。

## 实施与验证顺序

先接入持久化、结构检查和统一错误出口，再完成注册及登录会话、限流和前端页面。通过隔离 MySQL 库与 Redis 命名空间验证大小写唯一性、并发注册、CSRF、会话轮换、多设备退出和失效；通过可控时钟验证限流恢复与绝对期限。最后进行真实浏览器注册、登录、刷新和退出验证。应用不自动迁移，Flyway 由 ops 显式执行。
