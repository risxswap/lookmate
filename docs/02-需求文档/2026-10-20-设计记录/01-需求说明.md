# 设计记录前后端

日期：2026-10-20。用户已授权实施。沿用 [页面布局](../2026-10-20-前端页面与菜单布局/01-需求说明.md)、[领域模型](../../01-项目总览/02-领域模型.md#收藏与删除) 及现有工作台查询。执行见 [实施计划](02-实施计划.md)。

## 交付范围

设计记录页接入“全部记录”和“我的收藏”。全部记录支持模式、任务状态筛选和分页，进入已有详情；收藏支持收藏、取消收藏、按收藏夹浏览、创建／重命名／删除收藏夹、将同一收藏加入多个夹或移出某夹。删除收藏夹保留收藏和方案，取消收藏清除所有归属但保留方案。只有本人未隐藏且完整成功的任务方案可收藏；SUCCEEDED 为完整成功的权威状态，服务端还须确认方案存在。

沿用当前绿色 Ant Design 布局，显示加载、空数据、筛选无结果、刷新失败及重试。筛选改变回到第一页；查询键包含账号、筛选及页码，取消旧请求防止覆盖新结果。当前页包含活动任务时每 3 秒刷新，隐藏页面暂停、恢复立即刷新；UNKNOWN 不单独轮询。收藏操作成功后更新工作台、详情和列表缓存；失败不能显示假成功。删除收藏夹与取消收藏需明确说明影响，删除夹弹窗确认。重命名冲突保留输入，允许刷新服务器版本后由用户再次提交，不自动覆盖。

本轮不接入图片访问、任务重试、任务删除／隐藏及生成链路；这些操作依赖尚未实现的生成与文件清理／后台核实流程。继续提供新建设计入口。整体设计编码尚待生成模块细化，筛选提供已定义的 HAIRSTYLE、OUTFIT，不新增持久化编码。

## 接口契约

沿用会话身份、CSRF、`{data,requestId}`、统一错误结构、no-store、字符串 ID 和 UTC ISO 8601。所有写事务先锁当前 user，再按项目顺序锁相关资源；只读关联及计数均按账号和未隐藏任务过滤。不得接受客户端 owner。请求正文拒绝未知字段；文本严格为字符串。

分页 `page=1,pageSize=20`，page 为 1～2147483647 整数，pageSize 为 1～100；不传用默认值，空值或非法值 400 INVALID_REQUEST。响应 `{items,page,pageSize,total}`，页码与 total 为数字；越界页返回空 items 和真实 total。列表创建时间、ID 倒序。过滤参数不传表示全部，传非法或空枚举返回 400。

### 查询

- `GET /api/designs?page&pageSize&designType&status`：items 为 TaskSummary，筛选精确匹配 designType=HAIRSTYLE|OUTFIT；status 为现有七种任务状态。不返回隐藏任务。
- `GET /api/favorites?page&pageSize&collectionId`：按收藏 createdAt、id 倒序。collectionId 可选，非法 400，他人或不存在的收藏夹 404 COLLECTION_NOT_FOUND。items 为 `{id,resultId,createdAt,collectionIds,task}`，id 是收藏 ID，collectionIds 为字符串 ID 数组，task 是 TaskSummary。
- `GET /api/collections?page&pageSize`：items 为 Collection；Collection=`{id,name,version,createdAt,updatedAt}`，version 为非负十进制字符串，其他字段均字符串。UI 支持翻页，不以只加载前 100 个冒充全部。
- `GET /api/collections/{id}`：200 返回 Collection，用于重命名冲突后按 ID 读取当前版本；他人或不存在为 404 COLLECTION_NOT_FOUND，不依赖列表分页位置。

TaskSummary 在 [工作台字段](../2026-10-20-工作台/01-需求说明.md#接口实施约定) 基础上增加 `resultId:string|null`、`favoriteId:string|null`。工作台、记录列表、详情统一返回；actions 包含 VIEW，成功且有方案时按收藏状态返回 FAVORITE 或 UNFAVORITE，其他状态不返回收藏操作。现有字段语义不变。

### 收藏与归属

- `PUT /api/favorites/{resultId}`：无正文，成功 200，返回 Favorite（与收藏列表项相同）。已有收藏幂等返回原记录，不重置创建时间。
- `DELETE /api/favorites/{resultId}`：无正文，200 data:null；本人方案未收藏时同样成功，不删除方案；不存在／他人／隐藏方案统一 404 RESULT_NOT_FOUND。移除全部收藏夹归属。
- `PUT /api/collections/{id}/items/{favoriteId}`：无正文，幂等加入本人夹，200 data:null。
- `DELETE /api/collections/{id}/items/{favoriteId}`：无正文，幂等移出，200 data:null；保留收藏和其他归属。

收藏写入执行时再次验证归属、隐藏及状态；非成功返回 409 DESIGN_NOT_SUCCEEDED。夹不存在或他人夹为 404 COLLECTION_NOT_FOUND；收藏不存在或他人收藏为 404 FAVORITE_NOT_FOUND。

### 收藏夹

- `POST /api/collections`：`{name:string}`，201 返回 Collection。
- `PATCH /api/collections/{id}`：`{name:string,version:string}`，200 返回新 Collection。version 必须非负且不超过 Java Long；与当前不一致返回 409 VERSION_CONFLICT；成功递增。成员变化不递增名称版本。
- `DELETE /api/collections/{id}`：200 data:null，删除归属和夹，保留收藏及方案；不存在／他人夹统一 404 COLLECTION_NOT_FOUND。

名称先去除首尾 Unicode 空白，再 NFC 规范化；非空且最多 64 个 Unicode 码点。同账号规范化名称重复为 409 COLLECTION_NAME_EXISTS，英文大小写有区别。空／缺失／null／错误类型及超长返回 400 VALIDATION_ERROR。名字或版本无效不写入。

所有路径 ID 必须为正十进制字符串且在 Java Long 范围内，非法 400 INVALID_REQUEST。匿名 401，CSRF 错误 403，依赖失败 503；写操作不自动重试。以上状态错误只描述当前请求，不触发任务状态修改。

## 验收条件

1. 分页、默认参数、筛选、稳定排序、越界页、非法参数，以及隐藏和跨账号过滤一致。
2. 只能收藏自己的完整成功方案，重复收藏同一 ID，失败或未知方案不可收藏；列表和详情状态同步。
3. 同一收藏加入两个夹后，移出或删除其中一个夹不影响另一个；取消收藏清除全部归属，方案仍可查询。
4. 收藏夹空名、超长、未知字段、规范化重名被拒绝；大小写不同可共存；旧版本重命名不覆盖新值。
5. 页面可用真实数据完成筛选、详情、收藏、收藏夹管理与分组；加载、空态、错误重试和会话失效保持可用。
6. 验证真实 MySQL 事务／并发下重复收藏和归属不重复，异常回滚不留下半完成写入；前后端构建和 HTTP／浏览器联调，记录环境限制。
