# TDesign 按钮切换实施计划

## 范围与依据

依据用户最新确认，小程序按钮统一使用已安装的 TDesign 微信小程序版 1.17.0。沿用需求说明中的标题右侧新增、整行主操作、卡片按钮分行与窄屏布局。

## 实施任务 T1

状态为已完成。实现子 agent 完成组件切换及复验修复，主 agent 完成代码、静态绑定、43 项测试、类型与构建引用、原生编译及代表页面 UI 的独立复核。

- 将 17 个页面已有原生 button 标签切换为 t-button，补齐各页组件引用。普通操作使用 theme、variant、size、block 及组件设计 token。
- 核对原生 type、plain、hover-class 和事件与 TDesign 的属性差异。保留原事件处理器、数据参数、条件渲染、加载和禁用条件。
- 首页、设计、衣橱、我的页面中的按钮式卡片、分段筛选、图标按钮和菜单入口也使用 TDesign，针对组件宿主、内部根节点与内容容器适配现有布局，确保图片、标题及箭头正常展示。
- 公共按钮样式改为 TDesign token 和宿主布局规则，字号、高度、主次层级及小屏适配沿用本轮规范。
- 逐页核对页面绑定，运行构建、43 项现有测试与原生模板离线编译。主 agent 在微信开发者工具复核标题行、整行保存、照片卡片、参考详情及四个主页面中的代表交互。

## 验收与记录

所有页面源码按钮均使用 t-button，组件引用可构建，事件与数据参数逐页一致。320、375、390 宽度按代表页面检查，实际执行范围与待验证项写回需求说明、应用 README 和功能总览。已有工作区中的其他修改按当前状态保留。

最终构建为 629481 字节，129 个按钮模板完成切换。320、375、390 宽度的代表场景通过开发者工具复验，真机及完整业务交互待验证。证据见[需求说明](01-需求说明.md#tdesign-切换结果)。

## 实施任务 T2

状态为已完成。实现子 agent 调整了设计页共用参考详情容器，主 agent 已复核代码、原生编译与 390、320 宽度的固定操作区、正文滚动和关闭行为。

- 将详情改为固定的纵向容器，标题和底部操作区独立，正文使用 scroll-view 占据剩余高度。
- “使用此参考”与“收藏参考”沿用纵向整行 TDesign 按钮。操作区采用顶部 16rpx、左右 36rpx、底部 12rpx 间距，按钮间距 16rpx。
- 通过页面可用区域紧邻原生 tabBar，检查 iPhone 12/13 (Pro) 与 320 宽度机型的按钮间距、正文滚动、末尾说明可达和关闭详情。
- 执行构建及原生模板、样式编译，核对按钮事件、参数与状态条件，并将实际结果写回需求说明与功能总览。

T2 最终产物 629631 字节，构建、17 页依赖检查、wcc/wcsc 与差异检查通过。截图与真机待验证范围见[参考详情底部操作区调整](01-需求说明.md#参考详情底部操作区调整)。
