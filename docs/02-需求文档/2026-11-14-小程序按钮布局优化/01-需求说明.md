# 小程序按钮布局优化

## 最新组件选择

2026-11-14 用户确认按钮统一切换为 TDesign 组件，沿用本轮已调整的标题右侧新增、整行主操作、卡片按钮分行及窄屏规则。切换覆盖现有操作按钮以及首页、设计、衣橱、我的页面中使用 button 实现的筛选和导航入口。已完成 17 页共 129 个按钮模板的 TDesign 切换，具体结果见文末。下文原生按钮实施与截图为前一轮记录。

## 本轮要求

2026-11-14 用户要求检查小程序按钮布局并美化，调整按钮大小与标题、正文字体的比例，优先使用微信官方 UI 按钮。新增按钮与标题同排时放在右上角，保存、生成等操作按场景独占一行。

## 实施结果

本轮按局部界面优化实施，覆盖 17 个页面的按钮引用与公共样式。

- 将 98 个 TDesign 按钮改为微信原生 `button`，使用 `type`、`plain`、`loading`、`disabled` 和 `bindtap`。原有按钮的事件及 `data-*` 参数已逐页比对。带加载状态的按钮同步禁用，防止原生 `loading` 只显示进度时重复触发。
- 沿用暖白、墨绿主题，统一按钮圆角、内边距和按压反馈。普通按钮最小高度 44px，主按钮最小高度 48px。标准字号为普通 28rpx、主操作 30rpx、紧凑操作 26rpx，350px 以下分别使用 14px、15px、13px。
- 通用页面标题调整为 44rpx，分区标题为 32rpx。标题与按钮共用居中对齐的标题行，标题可换行，右侧操作保持靠右。常用搭配的新建、日历的添加安排和衣物照片的添加操作已应用。
- 登录、保存资料、保存衣物、保存搭配、生成及分页操作使用内容区整行宽度。身体尺寸保存、设计预检与提交、日历保存与取消、参考详情主次操作使用纵向排列。普通并排操作支持宽度不足时换行。
- 照片卡片中更换与删除分行，衣物图片内设封面与移除分行。收藏夹行内的改名、删除使用紧凑操作区。场景筛选按钮按内容宽度展示，输入框占据剩余空间。
- 页面配置中移除 `t-button` 引用，登录输入框继续使用已有 TDesign 组件。

微信官方 WeUI 小程序示例以原生按钮实现主操作、次要操作、警告、加载及小尺寸状态，本轮沿用这些原生能力。来源为[微信官方按钮示例](https://github.com/wechat-miniprogram/weui-miniprogram/blob/master/src/example/button/button.wxml)。

## TDesign 切换结果

用户确认后，依据[切换实施计划](08-TDesign按钮切换实施计划.md)完成了 17 页共 129 个按钮模板的替换。操作按钮及按钮式导航、分段筛选、图标入口、参考卡片和衣物卡片均使用现有 TDesign 1.17.0 的 `t-button`。

普通按钮使用 `theme`、`variant`、`size`、`block` 和组件 token，统一主次操作、描边、文本、加载及禁用状态。标题右侧新增、整行保存/生成、照片卡片分行与窄屏字号沿用本轮规范。图文入口通过 `t-class` 和插槽适配现有布局，设计主按钮的箭头使用 `suffix` 插槽。

本地 TDesign 装饰器在当前基础库启用 `virtualHost`，`class` 与 `t-class` 均作用于实际按钮根节点。复验中据此修正了首页查看全部按钮挤压标题、设计入口外边距和分段按钮文字对齐。自定义卡片使用自然高度，分类及辅助操作按内容确定宽度。密码折叠入口补充动态可访问名称，表达展开或收起表单的操作。

## 参考详情底部操作区调整

用户要求发型参考详情的“使用此参考”和“收藏参考”放到底部，更靠近原生底部导航栏。现有操作区位于 scroll-view 内，且添加了底部安全区留白，390 宽度模拟器中按钮与导航栏间出现较大空白。

本轮将详情调整为固定容器中的标题、可滚动正文和底部操作区，按钮与正文滚动分离。操作区底部间距定为 12rpx，使用页面可用区域与原生 tabBar 的边界对齐。设计页共用参考详情容器应用该布局，发型与穿搭参考详情同步使用。已实现并完成以下验证。


- `npm run build` 通过，类型、17 页路由及依赖检查通过，产物 629631 字节。
- 主 agent 独立核对了图片绑定、按钮事件、参数、状态与渲染条件，调整前后均一致。`wcc` 24 份 WXML/WXS、`wcsc` 23 份 WXSS 编译及 `git diff --check` 通过。
- 微信开发者工具中复验 390 与 320 宽度的发型参考详情，按钮保持在导航栏上方，底部间距约 6px（390 宽度）。正文可独立滚动到末尾，标题及操作区保持固定，关闭详情正常。模拟器最终恢复为 iPhone 12/13 (Pro)。真机待验证。
