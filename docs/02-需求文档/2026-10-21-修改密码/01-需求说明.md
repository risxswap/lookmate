# 登录后修改密码

日期：2026-10-21。用户已授权增加功能，并确认修改成功后所有设备退出、使用新密码重新登录。实施计划见 [实施计划](02-实施计划.md)。

## 范围与行为

登录用户从左下角账号菜单进入修改密码，入口位于“个人资料”下方、“退出登录”上方；填写原密码、新密码及确认密码。使用 Ant Design 表单和密码输入框，确认密码只在前端校验，不提交或持久化。密码沿用 [账号规则](../../01-项目总览/02-领域模型.md#账号与个人资料)：8～64 个 Unicode 码点，保留空格，不强制字符组合。

服务端从会话取得账号，验证原密码后更新密码哈希。新密码不得与原密码相同。未登录、原密码错误、字段非法或触发请求限制时不修改密码。并发修改只能有一个请求基于同一旧密码成功，失败请求不得覆盖已保存密码。密码及哈希不得出现在响应、日志或测试证据中。

本次不包含找回密码、管理员重置密码或设备管理。修改成功后当前会话立即结束，其他设备的旧会话在下一次请求时失效；当前页面清空账号查询缓存并返回登录页，显示成功提示。已在处理中的请求不承诺撤回。

## 接口实施约定

`POST /api/auth/password`，需要登录与 CSRF。JSON 仅接受必填字符串 `currentPassword`、`newPassword`，拒绝未定义字段、null 和非字符串值。成功返回 200，沿用 `{ data: null, requestId }`。

| 情况 | HTTP / code | 前端处理 |
| --- | --- | --- |
| 未登录或会话失效 | 401 / UNAUTHENTICATED | 沿用登录恢复流程 |
| 原密码错误 | 400 / CURRENT_PASSWORD_INCORRECT | 保留表单并提示原密码错误 |
| 长度、类型、未知字段、新旧密码相同 | 400 / VALIDATION_ERROR | 明确提示并允许修正 |
| 密码已被并发修改 | 409 / PASSWORD_CHANGED | 提示重新登录或核对最新密码 |
| 请求或验证失败达到限制 | 429 / RATE_LIMITED | 使用 retryAfterSeconds 提示等待并暂禁提交 |
| CSRF 不合法 | 403 / CSRF_INVALID | 沿用凭证刷新与手动重试 |

复用现有认证限流参数，为修改密码使用独立键，避免修改密码的失败计数干扰登录。哈希计算在数据库事务外完成，更新前验证原哈希仍一致；不改变个人资料的编辑版本。

## 验收与证据

验证正确修改、原密码错误、新旧相同、空值与类型、Unicode 长度和空格、未知字段、匿名与 CSRF 拒绝、限流、并发单赢家、旧密码不能登录和新密码可以登录。验证当前会话及另一设备旧会话均无法继续访问；并发旧密码登录不得产生可用的新会话。页面验证字段错误、重复提交限制及成功反馈；构建不能替代浏览器验证。
