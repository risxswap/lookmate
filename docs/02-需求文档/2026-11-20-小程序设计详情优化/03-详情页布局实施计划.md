# 小程序设计详情页布局实施计划

2026-11-26，适用于从设计记录、生成流程和收藏打开的同一详情页。

| 工作 | 实施与验收 |
| --- | --- |
| 刚进入详情 | 整理标题、类型、日期与可用操作。已成图的方案把对照入口放到图片上方，点当前图片能放大。核对无图、长标题、单张原照和图片重试。 |
| 阅读方案与查看进度 | 穿搭单品、发型打理、警示信息按内容呈现。保留设计理由折叠和搭配保存入口，本次参考独立展开。进行中按真实状态更新，失败、结果待确认和待找回提交使用已有业务操作。 |
| 状态与图片 | 页内切换使用当前任务已有的照片，轮询保留图像选择。参考展开才请求图片，避免重复读取。用户或任务变更时丢弃旧响应。 |
| 验证 | 定向与全量小程序测试、构建、微信原生模板编译。在 320px、390px 模拟器通过真实页面入口验证阅读、对照、菜单及异常任务。 |

上述改动已完成。173 项小程序测试通过，两种尺寸的微信模拟器已核对实际页面和操作，详见[验证记录与截图](../../testing/02-checks/2026-11-26-小程序设计详情.md)。
