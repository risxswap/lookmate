# 小程序设计详情优化实施计划

依据[需求说明](01-需求说明.md)，复用小程序 TDesign 组件、任务详情接口和现有图片访问能力。

## T1 小程序设计详情页面

执行者为实现子 agent，主 agent 复核与验证。修改 `apps/miniapp/src/pages/design-detail/index.{ts,wxml,wxss,json}`。若需要自动化回归，沿用小程序现有测试设施，覆盖图片失败隔离及调整后的操作入口。

- [x] 整理页面头、按比例展示的效果图和原照对照。图片各自加载，图片失败保留任务和方案，并提供恢复入口。
- [x] 集中收藏与更多菜单，穿搭单品旁显示常用搭配保存入口。复用原有状态守卫、确认、重试与待确认提交找回。
- [x] 展开现有核心建议，按实际内容展示穿搭、发型、详细理由、配色、参考适配和必要提示。生成中、失败与结果待确认使用紧凑状态区。
- [x] 在 `apps/miniapp` 下通过 `npm test`、`npm run build` 和微信原生模板编译。模拟器验证图片、对照预览、收藏、更多菜单、异常状态和无图表现。[验证记录](../../testing/02-checks/2026-11-20-小程序设计详情.md)
- [x] 主 agent 核对需求覆盖和实际交互，更新功能总览与导航。
