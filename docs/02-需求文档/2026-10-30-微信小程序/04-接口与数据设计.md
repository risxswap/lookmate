# 小程序接口与数据设计

2026-10-30 实施契约。新增接口沿用 `{data,requestId}` 与既有错误格式，ID 为字符串。真实微信、数据库迁移及跨端联调均未执行。

## 账号字段与身份

`Account` 保留 id、username（现允许 null）、displayName，新增 hasPassword:boolean、wechatBound:boolean、avatarFileId:string|null。独立头像通过既有文件访问授权取得链接，不使用本人照片字段。

小程序携带 `X-Miniapp-Token` 不透明凭证调用现有业务 API；token 属于 Redis 登录会话，30 天绝对有效，Web 继续 Cookie/CSRF。小程序写请求只在有效凭证核验通过后免 CSRF，公共微信登录交换入口单独免 CSRF。恢复不自动重放业务写操作。原生wx.request不支持PATCH，小程序使用POST并携带 `X-HTTP-Method-Override: PATCH`；服务端仅在X-Miniapp-Token核验通过后包装为PATCH，其他覆盖值或非POST覆盖拒绝400。Web与未认证请求不应用方法覆盖。

## 微信认证

- POST `/api/auth/wechat/login` `{code}`：服务端向微信交换身份。已绑定返回 `{status:"AUTHENTICATED",token,expiresAt,account}`；未绑定返回 `{status:"UNBOUND",ticket,expiresAt}`。ticket 5 分钟、单次注册或绑定，不能作为业务会话使用。
- POST `/api/auth/wechat/register` `{ticket}`：创建无用户名密码账号并绑定，返回上述 AUTHENTICATED 对象。
- POST `/api/auth/wechat/bind` `{ticket,username,password}`：验证旧密码并绑定，返回 AUTHENTICATED；冲突409 `WECHAT_ALREADY_BOUND`，不覆盖合并。
- GET `/api/auth/me`：现有入口可使用 miniapp token，返回 Account。
- POST `/api/auth/password`：既有入口。无密码账号400 `PASSWORD_NOT_SET`，改密使所有旧登录方式会话失效。

错误：400 VALIDATION_ERROR，401 WECHAT_TICKET_INVALID/UNAUTHENTICATED，409 WECHAT_ALREADY_BOUND，503 WECHAT_UNAVAILABLE（缺配置或供应商故障），502 WECHAT_LOGIN_FAILED（微信拒绝登录code）。不回显微信原文、openid或密钥。

## Web 扫码

浏览器请求需原有 Cookie，POST 保留 CSRF；二维码不能携带浏览器领取凭证。

- POST `/api/auth/qr` `{}`：同一浏览器会话旧未领取请求失效，创建新请求，返回 `{id,expiresAt,imageDataUrl}`；图片为微信小程序码 data URL，scene=id，页面 `pages/scan/index`。生成失败不返回模拟码。
- GET `/api/auth/qr/{id}`：仅原浏览器会话可查，返回 `{id,status,expiresAt}`；status=PENDING/CONFIRMED/CANCELLED/EXPIRED/CONSUMED。
- POST `/api/auth/qr/{id}/claim` `{}`：仅原浏览器单次领取 CONFIRMED，建立新Web会话，返回 Account；未确认409 QR_NOT_CONFIRMED，过期/取消410 QR_EXPIRED，非原浏览器404 NOT_FOUND。
- GET `/api/auth/wechat/qr/{id}`：小程序token鉴权，返回 `{id,status,expiresAt}`。
- POST `/api/auth/wechat/qr/{id}/confirm` `{}`：小程序token鉴权，绑定当前user和会话指纹，返回 `{id,status,expiresAt}`。
- POST `/api/auth/wechat/qr/{id}/cancel` `{}`：小程序token鉴权，取消待领取请求，返回 `{id,status,expiresAt}`。

5分钟有效、扫码不延长，刷新和取消失效；领取校验确认账号当前有效性与认证版本，已消费不能再次建立会话。注销浏览器会话后不能领取旧请求。请求和领取以数据库行锁协调。待确认码可由扫码账号取消；已确认但未领取的码只允许确认账号本人取消，消费后不可取消。claim先非锁读取账号定位，再按user→ticket锁定并复核payload和认证指纹，防止改密与领取竞态。

## 独立账号头像

- PUT `/api/profile/avatar` `{fileId:string|null}`：校验当前用户文件归属/可用性，在user短事务更新独立引用，返回 Account。null 清空，头像旧文件仍按全部引用检查后清理。
- 头像与昵称两端共用，昵称仍通过既有profile接口更新；Web和miniapp均通过Account avatarFileId获取短期文件链接。

## 数据与生命周期

V11（仅生成，不执行）：user.username/password_hash 可空；新增 wechat_app_id、wechat_open_id（组合唯一）、auth_version（改密递增）、avatar_file_id。user 行本身保证一个账号只绑定一个微信；唯一索引保证微信不能绑定两账号。新建/绑定在事务内，验密和微信HTTP在事务外；绑定锁user并复验验密时指纹。

新增 auth_ticket 表存一次性未绑定身份及二维码登录事务，具备 id、ticket_key、kind、owner_hash、payload、status、expires_at、created_at、updated_at；主键 id 为 BIGINT 自增，另设 ticket_key 随机32位字符串唯一索引用于公开定位；浏览器会话关联保存SHA-256哈希，不保存浏览器会话ID原文。业务会话仍仅使用Redis；auth_ticket是短期认证事务而非Redis通用数据。过期身份/二维码记录超过1天后分批清理；同浏览器刷新使用OWNER协调行串行化，OWNER行30天到期后清理。未绑定票据消费后清空身份payload。payload是服务端内部数据，不向客户端直接返回。

微信适配配置 `lookmate.wechat.app-id/app-secret/api-base-url/code-page/env-version`，密钥仅服务端配置。环境版本默认 develop 供开发体验；真实配置和权限须后续联调。所有外部调用有连接/读取超时，不在数据库事务中执行。

## 实施与离线验证（2026-10-30）

后端按本契约完成代码，V11 仅生成，应用启动结构检查已要求 V11。未执行数据库迁移，也未启动真实微信、七牛、模型或跨端联调；现有共享开发库不能在未迁移时直接启动本版。

已执行 `spotless:apply` 后的格式检查和编译，并通过32项离线检查：WechatAuthServiceTest 11、MiniappSessionTest 6、MiniappSecurityBoundaryTest 3、AccountAvatarServiceTest 3、ChangePasswordTest 5、AuthRateLimiterTest 4。覆盖无密码注册、绑定冲突/验密竞态、原浏览器单次领取、取消/过期/刷新、改密后的旧会话、绝对期限、伪造header、受限PATCH覆盖、Cookie CSRF保留、头像归属及引用切换、原密码空格与Unicode。

环境使用 Java 21，测试通过显式加载本机 Mockito javaagent 运行，避免受限环境下自附加失败。SecurityBoundary 使用内存 SecurityFilterChain/MockMvc，不开启 HTTP 监听或外部业务连接；数据库Mapper和Redis仓储用模拟替身，不能证明真实SQL、数据库锁或Redis持久化成功。

微信 code2Session 和小程序码官方文档本轮访问未成功，真实响应、版本权限和账号域名仍须后续核验；实现失败返回稳定错误，不使用模拟码或假登录回退。
