## 代码检查中修正的问题

- 使用有效小程序身份标记控制CSRF豁免，伪造请求头不能绕过；浏览器扫码端点不接受小程序凭证冒充原浏览器。
- 微信响应有界读取，令牌缓存与错误脱敏；扫码领取重验账号认证版本，改密后旧确认不能继续领取。
- 网络失败留在原页面；账号变更不重复跳转登录，旧响应、旧表单和上传步骤不能转入新账号。
- 写入失败保留表单与错误，不无条件刷新；筛选主动重试不受已有错误阻断。
- WXML条件必须使用表达式，表达式内不使用HTML转义的逻辑运算符；静态检查同步覆盖这类错误。
- 常用搭配表单有未保存修改时，阻止对旧搭配静默发起AI任务。
- 加载期间阻止筛选条件被悄然修改；模块级分页缓存按账号重置，防止切换账号后失败刷新混入旧记录。

## 离线编译复现

小程序目录执行 `npm run build && npm test`。本机原生编译器位于 `/Applications/wechatwebdevtools.app/Contents/Resources/package.nw/node_modules/wcc-exec/`；在 `apps/miniapp/dist` 下分别调用 `wcc -o <临时输出> <全部wxml及wxs文件>`、`wcsc -o <临时输出> <全部wxss文件>`。这些命令只读取构建文件并输出临时产物，不启动小程序或调用业务接口。
