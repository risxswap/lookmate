## 验证与交付

- 在 `apps/miniapp/` 使用项目要求的 Node.js 24 执行 `npm run build` 和 `npm test`；用微信开发者工具自带的 `wcc`、`wcsc` 离线编译构建模板和样式。
- 在可用的微信开发者工具模拟器核对窄／短屏、面板打开和关闭、正确测量线和数字输入保留；优先用隔离数据，不提交共享环境记录。真机键盘、安全区和触控如未操作，单独标为待验证。
- 实现与审查后在本计划记录实际证据，同步需求状态与功能总览；不把静态检查和模拟测试记为真机通过。

### 2026-11-19 实施与验证结果

- 图示取自 Web 的人体轮廓和测量线。小程序随包提供 48 张本地图（238,635 字节）；重制工具仅用于维护素材，不进入构建或运行。按资料性别选轮廓，缺省只影响示意图，不改个人资料。
- Node.js 24.22.3 下，`npm run build` 通过，构建目录文件合计 938,247 字节；`npm test` 通过 78 项，其中新增 8 项，覆盖全部字段的图文匹配、延迟收键盘回调、关闭保留输入、现有保存和历史操作。`wcc`（27 份 WXML/WXS）及 `wcsc`（25 份 WXSS）均离线编译成功。
- 微信开发者工具 2.02.2611182 Nightly 的 320×568 自定义机型使用隔离资料与历史夹具。核对身高和腰围标线、背宽的背面图、头围、本人左脚长与右脚宽，以及体重只显示文字。直接编辑身高至 171 时未弹图，查看后点遮罩关闭，输入仍在；关闭腰围和脚部图后对应分组仍展开。最终版窄屏图示和关闭按钮可见，没有横向溢出。
- 未调用业务环境写入接口，未发布。真机数字键盘动画、触控滚动和底部安全区待验证。
