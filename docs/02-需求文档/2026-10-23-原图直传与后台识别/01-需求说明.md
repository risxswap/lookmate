# 原图直传与后台识别

2026-10-23：用户已确认并授权实施，替代同日 Thumbnailator 上传预处理方案。

## 已确认行为

上传直接保存原始字节，不纠正方向、不合成白底、不转码、不生成缩略图对象。客户端直传七牛成功后，后端确认对象存在、所属账号、实际大小及存储报告的 MIME，即可作为 TEMP 文件保存照片或衣物；保存引用后为 READY。上传和保存不等待图片识别。

缩略图通过七牛 `imageView2/2/w/320/h/320` 参数获取，参数在私有 URL 签名前加入。DISPLAY 返回原对象私有链接。历史已处理资产继续按已有 storage_key 读取，不强制迁移或覆盖历史快照；历史缩略图可保留到正常清理，新图不再产生派生对象。

只接受 JPEG、PNG、WebP，单张不超过 20 MiB。上传链路不解码图片，不再执行原来的 2500 万像素与动态图检查，原图透明度及元数据保留。原图是否适合模型由后台业务执行时判断，失败不影响已保存图片。尺寸字段允许为空；格式及大小以后端从七牛取得的信息为准，不能仅信任浏览器声明。

沿用 server 内持久化的衣物识别后台任务与独立有界执行器：保存衣物时入队，识别完成回填，失败沿现有重试规则处理。个人照片不凭空增加未定义识别业务；不引入新服务、队列或泛化任务框架。生成结果同样不再另存缩略图；保留结果输入检查与恢复能力。

## 最小接口契约

- `POST /api/files/upload-intents` 请求与响应结构不变，返回 201；后端生成不可覆盖原图 key、限定大小和 MIME 的上传凭证。
- `POST /api/files/{id}/complete` 无请求正文，成功返回 200 与 FileDto（TEMP 或已绑定的 READY），幂等，不延长临时有效期。首次完成在事务外查询七牛对象信息，随后短事务重新检查归属、状态与有效期并落库。不存在/他人文件返回 404；未上传对象返回 409 `UPLOAD_NOT_COMPLETE`，可重试；格式或大小无效返回 400 `VALIDATION_ERROR`；存储暂不可用返回 503 `STORAGE_UNAVAILABLE`。并发完成/清理不能复活 DELETING 或过期资产。
- `GET /api/files/{id}` 保留查询能力，但新上传前端不轮询它。
- `POST /api/files/{id}/access` 仍接受 DISPLAY/THUMBNAIL；THUMBNAIL 生成带处理参数的签名 URL。权限及有效期沿用现有约定。
- 历史 UPLOADING/VERIFYING 可重试 complete 完成登记，不再启动旧图片加工任务；历史 TEMP/READY 与业务快照继续可访问。无结构迁移，遗留字段保留兼容读取和清理。

## 验收

上传原图不发生下载转码/派生图上传；complete 成功即可保存个人照片、衣物及提交设计。原图读取不变，缩略图查询参数参与签名。完成通知失败可重试且不重新上传。前端不出现核验等待及轮询，上传期间显示本地预览。衣物识别仍异步入队，不阻塞保存。覆盖存储缺失、非法类型/大小、他人资源、并发完成及清理边界；验证原有生成结果保存流程。
