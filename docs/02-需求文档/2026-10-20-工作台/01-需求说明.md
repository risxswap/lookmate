# 工作台前后端

创建日期：2026-10-20。

状态：用户已授权实现工作台前后端。只读数据、任务详情与页面状态已实现并完成开发验证，实施见 [计划](02-实施计划.md)，证据与限制见 [验证记录](../../testing/02-checks/2026-10-20-工作台.md)。

## 范围

沿用 [页面布局](../2026-10-20-前端页面与菜单布局/01-需求说明.md) 和 [领域模型](../../01-项目总览/02-领域模型.md)。保留开始形象设计及资料入口，展示本人进行中的任务和最近记录，点击记录查看真实阶段、失败提示和已保存方案文字。最近记录包含成功、失败及结果待确认，避免把失败任务从首页遗漏。

本轮工程选择：活动区最多显示 1 条；最近记录最多 6 条，包含所有非活动状态，按创建时间、ID 倒序；列表与详情均排除已隐藏记录。活动区空时显示无进行中的任务；最近记录为空时引导开始设计。接口失败明确展示错误与重试，后台刷新失败保留上次数据并提示可能过期。

仅活动状态每 3 秒刷新；页面不可见暂停，恢复可见立即刷新。UNKNOWN 不持续轮询。未登录沿用统一会话失效流程。

本轮不实现提交任务、AI 执行、重试、收藏、隐藏、删除及文件签名。开始入口进入已有设计页面；方案文字可以读取，效果图访问需等待私有文件服务，页面明确提示而不伪造图片。整体设计的写入编码和数据结构沿用原未决项，本轮不改 SQL 或模型配置。

## 接口实施约定

接口沿用 `{data, requestId}` 包装、统一错误格式和会话身份，不接受客户端指定账号。所有响应 `Cache-Control: no-store`。ID 使用十进制字符串；时间使用 UTC ISO 8601（Z），页面按浏览器本地时间展示。

### GET /api/workspace

200：`{activeTask: TaskSummary|null, recentTasks: TaskSummary[]}`。

TaskSummary 字段：

- `id`、`designType`、`status`、`createdAt`、`updatedAt`：非空字符串；状态使用 QUEUED、PLANNING、GENERATING、SAVING、SUCCEEDED、FAILED、UNKNOWN。
- `title`、`summary`、`errorCode`、`errorMessage`：字符串或 null；title/summary 取本任务所属账号的方案，无方案为 null。
- `actions`：当前只读交付返回 `["VIEW"]`；写操作尚未开放，不返回未实现的能力。

活动状态为 QUEUED、PLANNING、GENERATING、SAVING；最近记录查询 SUCCEEDED、FAILED、UNKNOWN。不依赖 user 的名额引用判断状态。

### GET /api/designs/{id}

200：TaskSummary 全部字段，加 `result: Result|null`。Result 包含字符串 `id,title,summary,style,occasion,designReason`，可空字符串 `colorAdvice,wearingAdvice`；`hairstyle` 为 null 或包含 `hairstyleName,lengthAdvice,bangsAdvice,partingAdvice,textureAdvice,hairColorAdvice,careAdvice` 的字符串对象；`items` 为数组，每项包含字符串 `dressId,dressName,categoryName,matchReason,wearingMethod`，按 sort_order、id 升序。无方案时 result 为 null；部分文字成功可以展示，但不描述为完整成功。

不返回输入原始 JSON、供应商配置、生图提示词、临时结果 URL、存储键、租约或执行权。所有关联查询同时校验 user_id。参数必须是正十进制、范围不超过 Java Long 的 ID；非法为 400 INVALID_REQUEST。不存在、他人或隐藏任务统一 404 DESIGN_NOT_FOUND。匿名 401 UNAUTHENTICATED，依赖不可用沿用 503。

## 验收

1. 新账号返回空活动区与空最近记录，前端展示真实空态。
2. 两账号隔离，隐藏记录不可见；非法、越权和不存在 ID 得到约定错误。
3. 各活动阶段真实展示；UNKNOWN、FAILED 与 SUCCEEDED 可见，排序稳定，最多六条。
4. 详情正确呈现已存方案与明细，不泄露内部字段，大 ID 不丢精度。
5. 活动轮询、隐藏暂停、恢复刷新、终态停止；加载、失败重试与会话失效可观察。
6. 前后端构建通过，并以隔离数据验证 SQL、HTTP 契约和真实浏览器页面；模拟数据证据与真实接口证据分别注明。
