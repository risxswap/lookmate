# 工作台实施计划

创建日期：2026-10-20。

依据：[工作台需求与接口](01-需求说明.md)。沿用现有 Java 21 / Spring Boot / MyBatis 及 React / Ant Design / TanStack Query，不新增依赖、不修改迁移，保留工作区已有页面布局改动。

## 任务与覆盖

| 编号 | 负责范围 | 覆盖 | 状态 |
| --- | --- | --- | --- |
| W1 | 后端子 agent：controller、service、mapper、DTO 与相关测试 | 验收 1–4、认证及依赖失败 | 已完成 |
| W2 | 前端子 agent：workspace 查询、工作台和详情组件、路由及局部样式 | 验收 1、3–5 | 已完成 |
| W3 | 主 agent：审查、集成验证、文档同步；修复交回实现 agent | 验收 6 与跨层字段 | 已完成 |

W1/W2 按已固定契约并行，文件范围互不重叠；W3 的集成运行依赖两端实现。

## W1 后端

- [x] 新增 WorkspaceController、DesignQueryController、WorkspaceService（Service 不另分领域包）、查询 Mapper 和 DTO；复用 AuthGuardFilter 可信账号和统一响应。
- [x] 参数绑定查询，固定上限与排序，所有关联带归属限制；只取契约字段。详情以只读事务读取一致结果。
- [x] 新增服务与真实 MySQL 集成验证，覆盖空态、状态、排序、隐藏、跨账号、ID 和内部字段隔离；不得用 mock 声称 SQL 验证通过。
- [x] `apps/server` 执行 Java 21 下 `./mvnw verify`；真实依赖测试按现有 LOOKMATE_INTEGRATION 开关执行并报告是否跳过。

## W2 前端

- [x] 新增 `features/workspace` 类型和查询模块、工作台与任务详情组件，替换 WorkspaceContent 内 Dashboard 骨架；只修改必要路由与样式，保留其他页面。
- [x] 接入 `/workspace` 和 `/designs/{id}`，使用字符串 ID、AbortSignal 与账号隔离 query key，状态显示不编造百分比。
- [x] 活动数据每 3 秒轮询，document 隐藏停止，恢复立即刷新；终态不持续刷新。错误、重试、旧数据过期与 404 分别展示。
- [x] `apps/web` 执行 `npm run build`；主 agent 进行真实浏览器空态、记录详情、失败及轮询检查。

## W3 交付

- [x] 审查规格覆盖、权限条件、查询排序及前后端类型；问题交回对应 agent。
- [x] 在隔离库与独立 Redis 前缀验证 HTTP 和页面，不迁移既有开发库。测试记录不得包含凭据。
- [x] 更新需求状态、功能总览、接口导航和相关 README；记录图片与生成链路依赖边界。

## 执行结果

W1 由 backend 子 agent 实现，W2 由 frontend 子 agent 实现，主 agent 完成规格与代码复核、HTTP 和浏览器联调。后端完整集成 verify 29 项通过，后补 MVC 回归 1 项通过；前端 build 通过。真实数据库、HTTP 及页面证据见 [验证记录](../../testing/02-checks/2026-10-20-工作台.md)。可见性以浏览器事件模拟验证，自然标签切换和并发快照专项未执行；图片及生成链路仍待对应模块实施。
