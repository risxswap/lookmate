# 发型图库与设计交互实施计划

日期：2026-10-29。用户已授权实施。依据[需求说明](01-需求说明.md)，沿用现有架构、数据库及接口规范。主 agent 协调、审查和验证，实现代码由子 agent 完成。工作区已有个人资料、工作台及文档修改，均须保留。

## 范围与契约

实现只改发型的图库与自由设计路径、同款多图、提交快照与预算、限制例外、结果对照及再试。最小接口与状态规则以需求末尾“实施契约与范围”为准。图库用版本化只读项目资源，历史版本随发布保留，无数据库迁移；新增资源不得冒充真实生成验收。少量代表款先覆盖男女常见款，真实供应商联调不以模拟测试代替。

## 任务与覆盖

### T1 平台图库素材（已完成）

- 子 agent 负责新增 `apps/server/src/main/resources/hairstyles/v1/` 下的 AI 示意图和目录JSON。与T2共享的目录格式先按契约约定，T2读取这些资源，不覆盖图文件。
- 制作至少6款（男女常见造型各3款），统一背景、构图及光线；至少一款有正侧两张图以覆盖多图展示。图片使用 imagegen 技能，保留生成来源记录，不使用人物照片冒充图库。
- 目录 `catalog.json` 包含数组款式，字段按Spec，图片为 `{id,angle,filename}`，版本v1；分类可覆盖 SHORT/MEDIUM/LONG、NONE/LIGHT/FULL、STRAIGHT/WAVY/CURLY。资源为不可变版本，配置维护无运营端。
- 检查图片文件可读、尺寸及目录一致；在需求目录写素材说明。

### T2 服务端目录与生成链路（已完成）

- 子 agent 负责新增HairstyleController、HairstyleCatalogService及必要DTO；修改GenerationService/Engine/Executor、GenerationGateway/HttpGenerationGateway及相关测试。读取Java专项规范。
- 提供鉴权分页、筛选、详情、受控资源路由；严格拒绝路径穿越与非法参数。
- 增加可选输入字段、预览/历史快照、版本核对及染发例外；旧任务/旧请求兼容。
- 平台图片通过受控本地字节提供模型，不通过任意远程URL读取；模型接口支持可信图片字节与既有用户签名URL，统一限制张数/字节并校验。同款参考图同时用于规划与生图，重试沿用历史快照。
- 明确单图协议不支持选款生成，保留原自由设计；不更换密钥或默认供应商。覆盖目录下架/版本、预算、染发冲突、历史重试及未知字段校验。
- 在 `apps/server` 使用Java21运行Maven相关测试及编译；有隔离集成设施则运行相关集成验证，禁止迁移共享库。

### T3 前端交互（已完成）

- 子 agent 负责 `apps/web/src/features/generation/`、必要workspace结果组件和类型及对应前端测试，不修改个人资料或工作台已有修改。
- 主区域图库、右侧本人照片/目标/发色/要求/确认；详情抽屉、服务端筛选分页、同款多图，保留筛选位置。
- 路径切换保留草稿但隔离提交内容；更换款式保留本人照片与要求、清除例外。默认头像、未上传可浏览、接口失败/空态/加载状态完整。
- 确认展示目标与本次调整；结果显示旧快照目标、原图对照、理发要点，再试还原输入。
- 复用Ant Design和既有主题，在窄桌面上顺序堆叠且主要操作可达。运行Node24构建和相关测试。

### T4 集成审查与验证（已完成开发验证）

- 主 agent 核对接口、图资源、快照、预算、旧请求及三模式回归；缺陷交回相应agent修复。
- 通过隔离HTTP或已有harness验证真实服务响应，再用浏览器检查浏览选款、抽屉返回、分页筛选、模式切换、染发冲突、生成结果及再试；保留截图和结果，标明模拟供应商范围。
- 同步需求、功能总览、领域/架构/接口及必要数据库文档，记录实际命令和结果。只将有证据的能力标为完成，明确真实供应商及生产未验证。
