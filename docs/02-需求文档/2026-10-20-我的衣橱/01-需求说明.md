# 我的衣橱前后端

日期：2026-10-20。用户授权实现。依据：[领域模型](../../01-项目总览/02-领域模型.md#衣橱与分类)、[数据库](../../01-项目总览/04-数据库设计.md#衣橱识别与自动搭配的数据方案)、[接口](../../01-项目总览/05-接口契约.md)。执行见 [计划](02-实施计划.md)。

## 范围与依赖

实现本人单品的固定分类、分页、详情、新增、编辑、图片整组排序／替换、删除、逐图人工特征及识别状态。图片至少一张，首张为封面；删除单品保留历史设计引用。列表继承绿色 Ant Design 布局，提供真实加载、空状态及失败恢复。

新增依赖七牛文件上传／核验／访问；自动识别依赖 DeepSeek 配置。代码应使用真实集成适配器，未配置时明确服务不可用，不能使用假图片或假识别成功。真实供应商联调等待开发配置，不妨碍隔离业务验证。图片与识别执行按已有有界资源和执行权规则实现。设计生成与必穿单品提交、个人照片库不在本轮范围。

## 契约

所有私有接口须登录，写接口 CSRF；沿用 data/requestId、no-store、字符串 ID／version／imageRevision、UTC 时间、未知字段拒绝及严格 JSON 类型。无权读取按不存在处理。页码规则与设计记录一致。文本长度按 Unicode 码点计算；名称 trim 后非空，1–100，color 可空最多100、notes 可空最多1000。seasons 为 SPRING/SUMMER/AUTUMN/WINTER 不重复数组，空数组不限。PATCH 未传不改，显式 null 仅清空 color/notes；必填字段及 seasons/images 不可 null。

| 接口 | 输入与输出 |
| --- | --- |
| GET /api/dresses/categories | data 为 `{id,code,name,sortOrder}[]`，仅数据库七种固定分类 |
| GET /api/dresses | page/pageSize/categoryId；`{items: Dress[],page,pageSize,total}`，createdAt/id倒序 |
| GET /api/dresses/{id} | Dress |
| POST /api/dresses | `{name,categoryId,color?,seasons?,notes?,images:[{fileId}]}`；201 Dress |
| PATCH /api/dresses/{id} | 传入字段更新，images完整有序列表，元素 `{imageId}` 保留原图或 `{fileId}` 新增，两者互斥；200 Dress |
| DELETE /api/dresses/{id} | 无正文，200 null；不存在404 |
| PATCH /api/dresses/{id}/images/{imageId} | `{version,manualFeatures?,resetFeatureKeys?}`；200 Dress，冲突409 VERSION_CONFLICT |
| POST /api/dresses/{id}/recognition-retry | `{recognitionId,confirmUnknown?}`；202 Recognition；仅当前FAILED/UNKNOWN，UNKNOWN须true |

Dress：`{id,name,categoryId,color,seasons,notes,imageRevision,createdAt,updatedAt,images: DressImage[],recognition: Recognition|null}`。
DressImage：`{id,fileId,sortOrder,version,aiFeatures,manualFeatures,effectiveFeatures,recognitionId,aiCurrent}`。不返回存储key或模型内部快照。
Recognition：`{id,status,errorCode,errorMessage,createdAt,updatedAt}`，仅安全错误文本；PENDING/RUNNING轮询，UNKNOWN手动刷新。

特征白名单为 viewType、description、colors、pattern、styleTags、fit、materialDescription、details。viewType为FRONT/BACK/SIDE/DETAIL/OTHER；description最多4000码点，pattern255、fit100、materialDescription1000；colors/styleTags最多20个非空字符串、每项100；details仅neckline/sleeve/pocket/button四键，值可空或最多255码点字符串。所有特征可null；manualFeatures未传键不变，显式null覆盖AI值为未知；resetFeatureKeys删除覆盖键恢复AI值，不能与本次覆盖键重叠。当前图片集合不匹配的AI值标为历史，effectiveFeatures仅合并当前AI与人工值。

错误：400 INVALID_REQUEST/VALIDATION_ERROR；404 DRESS_NOT_FOUND、DRESS_IMAGE_NOT_FOUND、FILE_NOT_FOUND、CATEGORY_NOT_FOUND；409 FILE_NOT_USABLE、VERSION_CONFLICT、RECOGNITION_NOT_RETRYABLE、UNKNOWN_CONFIRMATION_REQUIRED；503 STORAGE_UNAVAILABLE/RECOGNITION_UNAVAILABLE。容量与暂时故障沿用429/503。提交失败保留表单。

识别准入另设数据库队列上限，统计 PENDING/RUNNING，不把历史终态计入容量。全局与账号阈值可配置，开发初始值分别为 100、20，尚未经过真实供应商容量验证。单实例准入临界区保持到创建事务结束，防止跨账号并发超额。新增或改图遇到容量不足仍保存单品，该次识别记为 FAILED、错误码 RECOGNITION_CAPACITY_EXCEEDED，释放输入引用并允许以后重试；显式重试遇到容量不足返回 503，保留原任务、不新增记录。

## 文件接口衔接

POST `/api/files/upload-intents` `{originalName,sizeBytes,mimeType}` →201 `{fileId,key,uploadUrl,token,expiresAt}`。前端FormData直传指定uploadUrl（token/key/file），再POST `/api/files/{id}/complete` 无正文→202 File；GET同路径→File。File为`{id,status,mimeType,sizeBytes,width,height,validationError}`。POST `/api/files/{id}/access` `{variant:'DISPLAY'|'THUMBNAIL'}`→`{url,expiresAt}`；只允许未过期TEMP或READY且本人文件。未配置返回503，不降级成本地公开文件。

JPEG/PNG/WebP、20MB、2500万像素。真实核验、拒绝动图、方向纠正、去元信息、缩略图在有界后台执行，禁止信任客户端声明。上传补偿与租约恢复、临时24小时清理及全引用校验遵循架构。技术参数必须配置，保守开发默认值须标注待供应商验证，不冒称已确认容量。

## 验收

1. 固定分类与分页正确；两个账号无法互读互改，非法字段和类型明确失败。
2. 整组事务至少一图、重复文件拒绝、重排保留imageId与人工特征；每次集合变化恰好新增一次识别，纯文字修改不新增。
3. 过期／未核验通过／外部账号文件不能引用；保存、删除与异常回滚保持关联完整；删除不破坏历史任务文件引用。
4. 人工特征覆盖与清空／恢复不同；版本冲突保留输入；迟到识别不覆盖新集合或人工值。
5. 浏览器完成新增到编辑／删除链路；真实供应商不可用时用隔离适配器验证业务并明确真实集成未验证。
6. 构建与真实数据库测试通过，文档及脱敏证据同步，临时环境清理。

文件状态沿用数据库基线：UPLOADING → VERIFYING → TEMP（核验通过、尚未绑定），业务保存时转 READY 并清空临时过期与清理时间；REJECTED 为核验失败，DELETING 禁止使用。前端 TEMP 或 READY 可预览并提交，UPLOADING／VERIFYING 轮询，其余明确失败。识别未配置时保存单品和 FAILED 任务，安全错误码 RECOGNITION_UNAVAILABLE，不伪装正在识别；配置补齐后可重试。

2026-10-20 用户确认尚无七牛和 DeepSeek 开发配置。本轮继续实现并用隔离适配器验证，真实供应商上传、访问及识别效果留待配置后联调；不调用真实付费模型或用户对象空间。

## 实施结果

前后端及存储／识别适配已实现，沿用 V1，无新增迁移。68 项后端测试、38 项业务 HTTP 检查、最终构建 5 项定向检查及浏览器编辑／特征冲突恢复通过。具体证据及环境限制见 [开发验证](../../testing/02-checks/2026-10-20-我的衣橱.md)。验收第 5 项中真实新增上传到识别完成链路因供应商尚未配置而未验证，其余已执行范围逐项记于验证记录。
