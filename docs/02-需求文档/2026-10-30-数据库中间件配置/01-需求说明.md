# MySQL 与 Redis 中间件配置

2026-10-30 用户授权创建配置，放在 infra 中。实施范围为仓库配置与说明，不启动共享服务、不迁移数据。

沿用已确认架构：`infra/mysql/` 与 `infra/redis/` 各自维护 Compose、config、.env.example 和 README；MySQL 8.0.45、Redis 7.4.11 固定版本。端口、密码、数据路径及相关运行参数可配置，默认仅发布到宿主机回环地址，便于本地 IDE 连接。实际凭据和数据不入库。

MySQL 使用 utf8mb4/utf8mb4_bin，初始化空数据库与开发账号；业务表由 ops/Flyway 显式迁移，不挂载迁移 SQL 自动执行。Redis 仅用于会话，配置认证与持久化，避免重启即丢失会话；备份方案仍暂缓。两端健康检查、日志轮转和独立启停方式写入说明。

验收：配置可解析、参数引用一致、缺少密码时拒绝启动，默认不公开数据库端口，数据挂载独立且不随容器删除。README 对应现有 Spring 配置键，说明初始化参数只影响空 MySQL 数据目录。当前机器无 Docker，容器启动与连接检查若无法执行需如实记录。

实施步骤见 [实施计划](02-实施计划.md)。
