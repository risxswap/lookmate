## 交付内容

- 根 `package.sh` 转发至 `tools/package.sh`，支持 `server|web|infra|all`、`--version`、`--output` 和帮助。默认 all，默认输出 `output/packages/`，默认版本使用 UTC 时间；已有同名成品拒绝覆盖。
- server 执行 Java21 Maven clean verify，交付可执行 JAR、独立 Compose、外部配置模板和配套 ops。web 执行 Node24 npm ci、类型检查及生产构建，交付静态文件、独立 Compose、Nginx 模板与宿主机入口示例。infra 只归集 MySQL/Redis 生产配置，不依赖 Java/Node。
- 五个组件分别维护 Compose，通过外部 `lookmate` 网络连接；仅 web 映射 `127.0.0.1:18081:80`。HTTPS 由已有宿主机 Nginx 承接，经 web 代理 `/api` 到 server。
- 应用从 `releases/<版本>/` 只读挂载程序，实际配置、runtime、data 独立保存。交付包只包含白名单文件、模板、SQL 与配套驱动，附构建信息、内部 SHA256SUMS 和外部 `.sha256`。
- ops 使用固定 Flyway 镜像，只开放 info/validate/migrate；V1–V11 SQL 未修改，Connector/J9.7.0 从同包后端 JAR 提取。Flyway12.4.0官方镜像仅 linux/amd64，ARM64 目标需另行准备并验证。

部署使用已有镜像，无应用镜像构建或离线镜像包。未新增 deploy.sh 或自动维护排空；更新、迁移和应用回退须按包内说明显式操作。原开发 Compose、Web 开发方式及本地迁移入口保留。

本机默认 Java8、Node25，与构建要求不符；使用已安装 JDK21.0.8及官方 Node24.22.0，命令如下：

```sh
PATH="/tmp/node-v24.22.0-darwin-arm64/bin:$PATH" \
JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home \
./package.sh all --version 2026.11.12
```

结果：退出0。Maven Spotless、clean verify 和 Spring Boot 可执行包构建通过；324项测试中172项通过、152项按既有环境条件跳过，0失败、0错误。没有开启真实数据库、Redis、供应商或浏览器联调条件。Web 类型检查与 Vite 生产构建通过，保留单个 JS chunk 超过500kB的构建提示，未在本次调整拆包。

压缩包检查覆盖外部和内部全部校验值、目录路径安全、无符号链接、无 macOS AppleDouble、无实际 .env/私钥/持久化目录、JAR 可执行清单、内嵌驱动一致性、V1–V11和版本模板。JAR 内也未包含 .env、.pem 或 .key 文件。

## 验证限制与部署前工作

本机没有 Docker CLI/daemon，Compose 解析使用官方独立解析器，不能证明容器启动成功。未执行容器内健康检查、数据重启保留、真实Flyway迁移、HTTPS登录/Cookie端到端、微信或外部存储/模型联调。固定镜像与配置已提供，实际目标架构、镜像拉取及进程权限仍需在部署机验证。

本次未修改宿主机 Nginx、证书或 reload，未操作共享库、远程机器或既有服务。首次部署按包内 README 准备真实配置，创建网络，启动中间件并等待健康，核对目标后显式迁移，再启动server/web并合并入口站点配置。当前应用需要V11；不能用缺少该结构的数据库启动新后端。
