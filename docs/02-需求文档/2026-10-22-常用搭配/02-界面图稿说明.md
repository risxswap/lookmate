## 打开方式

开发服务运行时访问 [常用搭配交互预览](http://127.0.0.1:5187/common-outfits-preview.html)。停止后，可在 `apps/web` 使用项目约定的 Node.js 24 执行 `npm run dev -- --port 5187` 再打开。

入口为 [预览 HTML](../../../apps/web/common-outfits-preview.html)，源码为 [React 预览](../../../apps/web/src/previews/CommonOutfitsPreview.tsx) 和 [预览样式](../../../apps/web/src/previews/common-outfits-preview.css)。不从正式应用入口导入，依赖沿用现有 React 与 Ant Design，不增加依赖。

所有衣物为代码绘制的示意插画，所有搭配、账号与评价为示例内容；不使用用户照片。操作仅修改页面内存，刷新后恢复初始示例。效果图入口只演示确认与反馈，不调用 AI 或上传照片，不提供真实生成结果。

## 可操作范围与预览假设

可操作：页面切换、单品增减、编辑保存、置顶与取消置顶、分组筛选、新建和删除分组、分组多选、文字评价加载与完成、照片选择占位和出图前校验。从工作台最近设计可进入“存为常用搭配”编辑；编辑离开时提供确认。右上角可切换列表空状态。

以下只用于图稿讨论，不作为新增已确认需求：

- 示例仅 4 套搭配、7 件有效单品；同为置顶时按示例 ID 倒序。未定置顶上限或正式首页展示数量。
- 示例保存要求名称非空、至少一个单品；正式字段约束待契约设计。
- 图稿用上装和下装检查出图完整性，示例不含连衣裙或连体衣。正式实现须遵守完整领域规则，不能照搬此判断。
- 分组筛选和卡片排序直接使用少量内置样本，无服务端请求、无前端切片分页。正式功能必须采用服务端分页及 Ant Design 分页组件。
- 评价为固定展示文案，重新评价只更新演示状态，不保存多份生成历史；生成后的真实效果图、历史图对比、失败重试和活动任务展示尚未制作。
- 同一页内状态不对应正式路由，未覆盖浏览器前进后退与刷新草稿恢复。
