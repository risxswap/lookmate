# 记住登录

创建日期：2026-10-24。用户授权增加记住登录，已完成实现和隔离开发验证。默认期限及交互是本轮采用的实施选择。

登录页增加默认不勾选的“记住登录”，提示在此浏览器保留 30 天。勾选后关闭并重新打开浏览器仍可恢复登录；从本次登录起最多 30 天，访问和轮询不延长绝对期限。未勾选保留会话 Cookie、空闲 2 小时和绝对 7 天的现有行为。期限可在服务端配置，页面提示与配置一致。

沿用 Redis 服务端会话、HttpOnly、SameSite=Lax、生产 Secure 与 CSRF。退出销毁当前会话，修改密码和账号停用继续使旧会话不可用。不保存密码到浏览器，不新增表或独立令牌。旧会话缺少记住标记时按普通会话处理。重新登录时轮换会话 ID，清理旧记住状态；登录失败不得建立或延长记住登录。

接口：POST /api/auth/login 增加可选布尔 rememberMe，缺省 false，显式 null、字符串和数字拒绝；其他请求字段与响应不变。注册仍只接受 username、password，不接收 rememberMe。GET /api/auth/config 可增加记住期限（秒）供页面展示。身份、资源权限及错误响应沿用登录注册契约。

验收覆盖：普通与记住登录的 Cookie、服务端有效期和绝对边界；浏览器重开恢复；记住切回普通；退出与密码变更失效；字段非法类型、缺省兼容及注册拒绝；前端选项提交、失败保留、构建和既有测试。运行验证必须使用隔离会话／测试数据，无法运行项如实记录。

原规则见 [登录注册](../2026-10-20-登录注册/01-需求说明.md)。实施见 [实施计划](02-实施计划.md)。

## 实施与验证（2026-10-24）

登录新增独立 LoginParam，注册字段边界保持不变。成功验密后重建 Spring Session 会话，普通登录恢复默认 2 小时空闲期限，记住登录保存会话标记并设置 30 天 TTL；后续请求将 TTL 缩短至绝对期限剩余时间。Cookie 序列化按当前会话设置有效期，复用部署的名称、域、路径、HttpOnly、Secure、SameSite 和 Partitioned。剩余不足 1 秒时 Cookie 向上取整到 1 秒，服务端仍按毫秒校验绝对期限。

登录页增加默认不勾选的 Ant Design Checkbox，失败保留选项，注册不发送 rememberMe。提示使用配置返回的 rememberMeSeconds，按整天、小时、分钟或秒展示；旧后端缺少该字段时仅显示通用提示，不显示 NaN。记住期限配置要求正整数秒且不超过 Integer.MAX_VALUE，启动校验拒绝 null、小数或越界值。

验证命令与结果：

- `cd apps/server && ./mvnw -q spotless:apply verify`：退出码 0；最终 Surefire 合计 198 项、0 失败、0 错误、80 跳过，实际执行 118 项。跳过项为依赖外部环境的既有集成测试和显式启用的浏览器 harness；本轮不把这些跳过项算作通过。
- `cd apps/server && ./mvnw -q test -Dtest=RememberLoginTest,SessionCookieConfigurationTest -Dlookmate.test.redis=true -Dspring.data.redis.port=16389 -Dspring.session.data.redis.namespace=lookmate:remember:final`：退出码 0，11 项中执行 10 项、浏览器 harness 跳过。使用本轮独立无持久化 Redis 进程、真实 HTTP、Spring Security、Spring Session 与 Cookie 序列化；AuthService 受控替身，不访问业务数据库。覆盖普通/记住期限、真实 Redis TTL、绝对边界、切回普通、退出、密码指纹拒绝、非法字段及失败不延长期限。
- `cd apps/web && npm run build`、`node --test tests/*.test.mjs`：退出码均 0，前端 25 项通过；构建仍有已有包体积提示。
- 浏览器使用独立 Chrome profile、Vite 15173 与隔离认证后端 51104，验证默认不勾选、30 天提示、登录失败保留勾选、成功进入工作区、持久 Cookie 与关闭重开后 `/api/auth/me` 返回 200。观察到 CLI 立即关闭会早于 Chrome Cookie 数据库落盘，重开取到旧匿名 Cookie；等待持久 Cookie 落盘后再次关闭并启动新浏览器进程，登录恢复且 Cookie 截止时间不变。隔离后端仅加载认证模块，工作台业务接口错误不作为本轮业务验收。
