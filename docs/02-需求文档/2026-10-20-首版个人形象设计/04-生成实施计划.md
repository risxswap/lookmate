# 完整生成链路实施计划

创建日期：2026-10-21。状态：代码实施及开发验证完成；真实供应商联调未完成。用户本轮明确授权同时实现页面、提交、任务执行与结果展示；沿用已确认简化算法。业务依据见 [需求](01-需求说明.md)、[算法](02-穿搭算法设计.md#10-首版简化方案2026-10-21-已确认待实现)，协议以 [生成技术契约](03-生成技术契约.md) 为实施基线，以下技术选择在本轮落实并以实际验证更新。

## 范围与全局约束

实现 HAIRSTYLE、OUTFIT、OVERALL 三模式，预览、幂等提交/找回、任务处理、持久化结果、按 actions 手动重试、页面输入与结果。采用草案的无模型签名预览、NO_MATCH 映射 FAILED 及 V3 outcome_snapshot 字段；它们是本次实现选择，不改变业务规则。真实模型标识、渠道地址/参数及图片预算无已验证值，默认关闭生成并明确返回 GENERATION_UNAVAILABLE，不使用假结果代替真实功能。

程序候选筛选、一次规划、严格校验及一次生图；不增补模型审核或自动重生。本人图片与候选引用先固定，外部调用在事务外；UNKNOWN 不自动重发并释放账号名额，可靠暂存后的失败只恢复保存。单账号关联写入先锁 user，遵守既有锁顺序；容量有界，设计与识别共享规划供应商限额且避免识别饥饿。密钥不入任务快照或日志。不得修改 V1/V2，不迁移共享开发库，不调用付费供应商。

### T2：算法与模型接入（算法 agent）

负责 `GenerationEngine`、`GenerationGateway`、`HttpGenerationGateway`、`GenerationFailure` 及算法相关服务/DTO/测试，供应商适配使用既有 HTTP 工具且严格单次调用。不改 T1 的属性和持久化文件。

共享接口：`GenerationGateway.Image` 使用 Lombok 值对象，字段 `imageId, url`，提供全参构造及 getter。`GenerationGateway.plan(Map<String,Object> config, String systemPrompt, String userPrompt, List<Image> images)` 返回模型内容 JSON 字符串；`generate(Map<String,Object> config, String prompt, List<Image> images)` 返回图片字节 `byte[]`，有界下载/解码，不自动重试。`GenerationFailure` 提供 `getCode()`、`isUncertain()`。

`GenerationEngine.selectCandidates(List<Map<String,Object>> wardrobe, List<String> requiredIds, Map<String,Object> preferences, long seed, Map<String,Object> budgets)` 返回候选 Map 列表。每件候选字段 `dressId, name, categoryCode, categoryName, color, seasons, notes, images`；图片字段 `imageId, fileId, sortOrder, features`，features 已由调用者合并人工与当前有效 AI 字段。

`GenerationEngine.plan(Map<String,Object> snapshot, Map<String,Object> config, List<GenerationGateway.Image> images)` 单次调用规划并返回已校验结果 Map（kind/plan/constraintChecks/requestConstraints/noMatch）。snapshot 字段沿契约：designType、normalizedRequest、personalContext、effectiveConstraints、candidateItems、recentOutfits、budgets；images 的 imageId 为本人 `person:<fileId>` 或衣物图片 ID。`GenerationEngine.imagePrompt(Map<String,Object> snapshot, Map<String,Object> validatedOutput)` 返回由服务端边界和已验证穿法组合的文字提示。T1 必须在调用 plan 前确定并记录实际送模图片，生图只发送本人及选中图片。

配置 Map 键：`planEndpoint, planModel, planApiKey, imageEndpoint, imageModel, imageApiKey, imageParameters, timeoutSeconds, maxResponseBytes`；密钥仅调用时注入，不持久化。预算键：`candidateTarget, planningMaxImages, imageMaxImages, maxInputBytes, maxTextChars`，规划图片张数包含本人照片，必穿不静默删除。配置未验证时 T1 不开放调用，T2 同样拒绝缺失关键参数。

- [x] 稳定种子、分类额度、多样性、必穿覆盖、缩减后基础路径保留；未知信息不硬排除。
- [x] 一次规划提示涵盖硬软限制、天气、正常穿用与遮挡、示意鞋、三模式、历史及隐私边界。
- [x] 唯一 kind/plan/noMatch schema、未知字段/长度/ID/图片归属/必穿/限制/模式/鞋提示校验，无修复调用。
