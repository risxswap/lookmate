# 搭配详情大图返回闪烁

用户反馈，查看大图后回到小程序搭配详情，图片会闪动。预期返回后仍能看到原先浏览的图片及位置，生成任务状态和真实发生的搭配变更应能正常更新。

详情页在 `onShow` 时重新读取搭配，原逻辑会为每件单品重新获取缩图地址并写回列表。单品没有变化，重新签名也会生成不同的 URL，导致图片组件重新加载。

## 修复前复现

微信开发者工具 Stable 2.02.2608080（基础库 3.18.0）中，记录一套三件搭配的缩图地址，点击第二件裙子，原生预览显示「2 / 3」。关闭预览后回到原页面，三张缩图中保留原地址的有 0 张。离线测试以两件单品重放相同的隐藏、显示生命周期，缩图授权请求从 2 次增至 4 次。

## 修复与验证

搭配内容一致且单品缩图齐全时，详情页保留已显示的单品和拼图，继续查询当前生成结果。单品缩图使用按账号和文件区分的本地图片缓存。某张缩图失效时清除该图，下次刷新可重新获取。

在同一模拟器、同一搭配上重新打开第二件裙子的大图并关闭，3 张单品缩图全部保留原地址。两件单品的回归测试中，预览往返后缩图授权请求保持 2 次。另已覆盖返回时生成结果更新、替换单品图片、单张缩图失效恢复和迟到的旧图错误事件。小程序构建、详情页 WXML 原生编译和全部 70 项测试通过。真机表现待验证。
