# 小程序编译找不到 dist/app.json

2026-11-19 已恢复本机编译，微信开发者工具模拟器可显示登录页。

## 复现与原因

- 微信开发者工具日志显示：`miniprogramRoot` 指向 `dist/`，但该目录下找不到 `app.json`。`dist/` 是本地构建产物，不提交到 Git；故障时工作区也没有小程序的 `node_modules/`。
- 在 `apps/miniapp/` 运行 `npm run build` 复现退出码 2。依赖缺失导致 `tsc` 用了全局 TypeScript 5.0.4，而非锁定的 6.0.3。类型检查报 `TS2688`（找不到 `miniprogram-api-typings`）和 `TS5103`（不接受项目的 `ignoreDeprecations` 值），因此构建未生成 `dist/`。

## 处理与验证

使用 `.nvmrc` 指定的 Node.js 24（本机安装 v24.22.3），在小程序目录执行 `npm ci` 恢复锁定依赖，再执行 `npm run build`。未修改应用源码、依赖版本或 `miniprogramRoot`。

- `npm run build` 通过，`dist/app.json` 已生成，登记 17 个页面。本地 `tsc` 返回 6.0.3。
- `npm test`：70 项通过、0 项失败。
- 已打开的微信开发者工具重新加载构建产物，模拟器显示登录页，调试器显示 0 个错误。未执行登录或真机验证。
- 微信开发者工具的服务端口关闭，CLI `open` 仍不可用；本轮通过已打开的界面复验，未更改安全设置。通过 VS Code 启动项调用 CLI 时仍需按小程序 README 开启该端口。
