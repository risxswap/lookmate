# 衣橱列表滑动图片闪动修复计划

## 目标与范围

用户已要求修复普通滑动图片闪动，并指定参照发型参考列表。依据同目录问题说明，修复衣橱衣物和同页常用搭配的卡片按压反馈、图片地址稳定性及无后续页时的重复加载。

## 实施任务 T1

状态为已完成。实现子 agent 完成代码及针对性回归检查，主 agent 完成审查、独立核验和开发者工具滚动复验。真机及实际下拉刷新手势待验证，详见[验证结果](01-问题说明.md#验证结果)。

1. 在衣橱 WXML 中对图片卡片使用无透明度变化的触碰反馈，继续使用 TDesign 按钮、服务端分页、固定封面区域和 aspectFill。
2. 复用现有图片下载与账号校验，按发型参考封面方式为文件封面提供有界的本地临时路径缓存。按账号、文件 ID、图片版本隔离，并合并同一图片的并发请求。失败缓存释放后可重试，账号切换期间的旧响应继续拒绝。
3. 衣橱加载及追加页复用旧封面的稳定本地路径，只为缺失图片申请签名与下载。图片失败按单张处理，保留已有成功封面及列表信息，提供刷新或重试。组件图片加载失败时允许释放对应缓存，恢复后可重新加载。
4. 常用搭配沿用 outfitCards 的字段映射，可提供默认兼容的封面解析入口，使衣橱共用上述封面加载。
5. 无后续页时停止触底处理，保留首次加载失败后的第一页重试、筛选刷新与账号保护。
6. 对本次明确缺陷补充回归检查，证明修复前触底重新申请图片或旧地址变化，修复后地址和下载次数稳定。覆盖有下一页追加、刷新、图片失败重试、并发复用及账号切换。

允许修改 miniapp 的 lib/files.ts、features/outfits.ts、pages/wardrobe/index.ts / index.wxml / index.wxss 及必要的现有测试文件。保留工作区其他任务的修改。

## 验收

构建、相关测试和原生编译通过。开发者工具中核对衣物与常用搭配的触碰、连续上下滚动、触底、下拉刷新及详情往返。需要区分测试替身证明的请求次数与模拟器观察到的呈现，真机未执行时在交付中列明。
