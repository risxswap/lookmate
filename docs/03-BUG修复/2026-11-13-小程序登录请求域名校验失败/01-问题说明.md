# 小程序登录请求域名校验失败

日期：2026-11-13。状态：已定位，微信后台配置及修复后复验待完成。本次仅诊断，未修改业务代码或微信后台配置。

## 现象与证据

在微信开发者工具打开 `apps/miniapp/`，点击“微信登录”，页面显示“网络连接失败，请检查网络后重试”。工具版本为Stable 2.01.2510290，基础库3.18.0。

本次直接读取正在运行的开发者工具Console，已有日志记录：

```text
Fri Nov 13 2026 10:50:52 GMT+0800 (中国标准时间) request 合法域名校验出错
https://lookmate.labno3.com 不在以下 request 合法域名列表中
```

控制台列出的request合法域名只有 `https://tcb-api.tencentcloudapi.com`，并提示后台更新域名后通过“详情-域名信息”刷新项目配置、重新编译。

## 根因与建议

小程序请求地址为 `https://lookmate.labno3.com/api/auth/wechat/login`。项目和本地项目配置均启用 `urlCheck: true`；开发者工具当前使用的request合法域名列表不包含服务域名，请求被本地校验拦截。本次证据尚不能区分后台未添加与后台已添加但工具配置未刷新。

`apps/miniapp/src/lib/request.ts` 的 `wx.request.fail` 统一抛出“网络连接失败，请检查网络后重试”，因此页面没有展示具体域名校验原因。现有证据不指向微信凭据错误或服务端登录业务错误。

在对应小程序管理后台的服务器域名配置中核对并添加request合法域名 `https://lookmate.labno3.com`，填写域名本身，不带 `/api` 路径；保存后在开发者工具“详情-域名信息”刷新配置，重新编译并重试登录。

## 验证边界

此前同日HTTPS健康检查返回HTTP 200、`UP`，证书校验通过；该检查不能代替微信合法域名校验。本次未再次点击登录、未调用真实登录接口，未更改域名校验设置。

配置生效后应观察到：Console不再出现该域名校验错误，Network中出现登录POST请求；随后再根据接口响应验证登录或首次注册/绑定流程。目前未执行修复后验证，不将定位完成记为登录验收通过。
