# 小程序衣橱打开报错

## 现象与原因

2026-11-19 在微信开发者工具的隔离验证项目中，点击底部「衣橱」后只显示「全部」和 0 件衣物，并提示 `Cannot read properties of undefined (reading 'find')`。同一项目的模拟数据实际包含 22 件衣物。

模拟接口漏配了 `GET /api/dresses/categories`，请求被通用衣物详情路由接收，返回 `undefined`。衣橱页读取分类名称时对这个值调用了 `find`，因此衣物列表和总数没有写入页面。现行[衣橱接口](../../02-需求文档/2026-10-20-我的衣橱/01-需求说明.md)定义分类数据为数组。

## 修复

补齐隔离项目的分类数据与分类筛选逻辑。小程序在分类请求入口校验返回值是否为数组，异常时显示「衣物分类加载失败，请重新加载」，衣橱页可使用已有的「重新加载」入口重试。

## 验证

- 微信开发者工具 Stable 2.02.2608080、基础库 3.18.0。修复前复现了截图中的 `find` 异常。重新编译后，从首页点击「衣橱」可见两项分类、22 件衣物的总数及首批衣物卡片。点击「下装」显示 0 件和分类空状态，切回「全部」后恢复 22 件。
- 新增回归覆盖分类响应为 `undefined` 和重试恢复。修复前未显示预期的分类错误提示，修复后重试可恢复衣物总数、分类名称和封面。
- 小程序 `npm test` 共 97 项通过，`npm run build` 通过。真实后端与真机待复验。
