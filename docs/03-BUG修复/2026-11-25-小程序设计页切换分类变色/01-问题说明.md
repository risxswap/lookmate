# 设计页切换分类时，其他分类短暂变灰

2026-11-25，在微信开发者工具 2.02.2608080、基础库 3.18.0 的 390px 模拟器中，打开「设计 → 发型」，点「穿搭」，让隔离图库请求保持等待。[设计页布局](../../02-需求文档/2026-11-13-小程序视觉优化/01-需求说明.md#2026-11-25-设计页图库布局)

等待时，「整体」和「只看收藏」的文字从灰绿 `#666f65` 变为半透明黑色 `rgba(0,0,0,.26)`，透明底色变为浅灰 `#eee`。「穿搭」已显示选中下划线，但也出现灰底。请求完成后颜色恢复。

图库读取期间，页面用 `busy` 禁用分类按钮和收藏筛选，防止重复操作。TDesign 1.17.0 的默认禁用样式同时改变按钮文字和背景，因此连未点击的分类也出现了颜色变化。

## 修复与复验

设计页为分类按钮和「只看收藏」指定加载时的文字色与透明底色，沿用原有选中样式与禁用逻辑。[页面样式](../../../apps/miniapp/src/pages/design/index.wxss)

用相同的延迟请求复验。从「发型」点到「穿搭」后，下划线移到「穿搭」。在加载中、加载时再点「整体」、请求完成三个阶段，「整体」的字色均为 `#666f65`，底色均为透明。「只看收藏」关闭时同为 `#666f65`，打开时保持墨绿 `#304f40`。重复点击后仍显示本次选择的「穿搭」。[修复前加载中](02-修复前加载中.png) · [修复后加载中](03-修复后加载中.png)

小程序 145 项测试、构建、微信 `wcc` 和 `wcsc` 原生编译均通过。本次交互复验使用模拟器与隔离数据，真机未复验。
