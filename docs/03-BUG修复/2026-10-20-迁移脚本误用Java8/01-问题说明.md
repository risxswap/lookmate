# 迁移脚本误用 Java 8

状态：已修复，启动选择逻辑已验证；未执行实际数据库迁移。

运行 `bash ops/migrate.sh migrate` 时提示无法加载 `RunMigration.java` 对应的主类。终端的 JAVA_HOME 指向 Java 8，旧脚本直接沿用该变量；Java 8 不支持源码文件启动，因此把文件路径当作类名。

迁移脚本现在先校验 Java 21。macOS 当前版本不匹配时，通过系统 java_home 工具查找 Java 21；仍不可用时给出明确错误并退出。选定的 Java 主目录同时传给 Maven，保证两者一致。

验证：使用临时共享配置和模拟 Maven，分别从 Java 8、Java 21 及无效 JAVA_HOME 启动，均成功选用本机 Java 21.0.8，并传递共享数据库配置及 migrate 动作。Shell 语法检查通过。模拟进程未连接数据库。
