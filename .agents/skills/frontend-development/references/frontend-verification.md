# 前端验证

从项目构建配置、依赖锁文件和 CI 读取实际命令，沿用已有类型检查、静态检查、构建和测试设施。只有新变更或失败需要时扩大检查范围，不为已通过的简单修改重复全量运行。

组件或界面测试验证用户输入、事件和显示结果，异步测试覆盖旧请求晚到、错误与取消。类型检查不能证明响应运行时正确；构建成功不能证明目标平台交互可用。

按目标平台验证受影响界面、关键状态、导航与适用的输入方式：Web 使用真实浏览器；小程序使用对应开发者工具并按涉及的平台能力补真机验证；客户端使用对应模拟器或真实安装环境，设备专属能力在适用设备验证。只运行了模拟环境时明确其覆盖边界。

涉及布局、视觉或设计规范时，按 [界面设计](interface-design.md#实现后的设计检查) 对照需求和设计依据检查实际呈现，保存相关截图与问题复查结果。正式 UI 黑盒测试按已确定范围交给 `ui-testing`，沿用同一设计依据，不重新发起设计流程。

记录环境、场景、实际结果和证据。缺少服务、数据、开发者工具或设备时说明未验证范围；截图和静态源码审查不等于流程验收。沿用公共 [验证与交付](../../development-workflow/references/verification-and-delivery.md) 汇总结果。
