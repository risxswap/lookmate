## 补充与冲突

Spring 事务代理、框架配置、JPA 抓取、Vue 异步状态等来自对应参考内的官方框架说明或本套工程实践，不赋予阿里等级。官方文档链接可能滚动更新，使用具体 API 前核对项目版本。

发现现有项目规则与表中默认不同，记录“规则 ID、项目事实、采用方式、影响范围”。对新需求提出适当方案；未经范围授权不修改历史 schema、认证方式或公共协议。P3C 工具只是部分规则实现，兼容性和通过结果均不能替代本表的人工及行为验证。

增加规则时先核对原文版本、等级和定位，再更新本表和相关执行参考；不要把整个手册隐式升级为本套强制基线。
