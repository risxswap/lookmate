# API 与服务端安全

A11–A13、A15 的来源见 [规则映射](alibaba-rule-mapping.md)，其他内容为本套补充。

沿用认证方式和 HTTP 契约，不预设 JWT、OAuth 或统一响应类。参数在边界检查类型、范围、长度、嵌套对象及分页大小，状态转移与数据权限在服务端验证。校验注解需验证确实被触发，而不只是出现在 DTO 上。

身份从可信认证上下文取得，不能信任请求传来的 ownerId、tenantId 或角色。访问具体对象时校验该用户对该对象和操作的权限；批量、导出与查询计数沿用相同数据范围。角色许可不替代对象归属验证，前端隐藏按钮不替代后端校验。

响应只暴露契约字段，日志与错误消息不泄露凭据或完整敏感数据。支持超大 ID 时用字符串传输；类型与兼容性见公共 [契约协作](../../development-workflow/references/api-contract-collaboration.md)。

涉及浏览器认证时核对实际 Cookie/Token 模式：Cookie 自动携带凭据的请求需按框架机制防范 CSRF，跨域只开放必要来源。不要为联调全局关闭安全机制。密码使用项目安全框架的密码哈希能力，不以普通摘要或可逆加密代替密码存储。

文件上传限制实际大小、格式和保存路径，服务端生成文件标识；下载执行授权和路径范围校验。外部 URL、动态排序字段、跳转地址按目标业务限定可选值，用户输入不直接进入 SQL、命令或内部网络请求。

接口变化同步成功、失败、权限及边界示例。至少验证未登录、已登录但无权和合法操作三种相关路径，避免只测试管理员账号。
