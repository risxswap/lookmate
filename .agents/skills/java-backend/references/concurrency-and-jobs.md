# 并发、任务与外部调用

A17 的线程池规则及现代运行时适配见 [规则映射](alibaba-rule-mapping.md)，以下为本套补充。

先确认是否确需并发。使用受管理的执行器，明确并发上限、排队容量、拒绝策略、任务超时、异常记录与关闭方式；不能把默认无界队列视为安全配置。使用虚拟线程仍需限制数据库连接和下游并发，不因线程便宜放弃容量控制。

共享可变状态明确同步边界，锁及时释放；中断按调用约定传播或恢复标记，不吞掉取消信号。异步工作不能假定继承调用线程事务、安全上下文或日志上下文，需要时显式传递与清理。

定时任务区分单实例执行和多实例竞争。业务唯一约束、任务认领或既有调度设施应支持重复触发后的正确性；不默认添加分布式锁。失败任务记录状态和可重试条件，避免无期限重试。

第三方 HTTP 配置连接与读取超时。重试仅适用于确定可重试的失败；有副作用的请求必须具备幂等保障或核对机制。明确最大次数、总时限与退避，错误不能转换为假成功。验证超时、失败与取消路径，避免真实支付、邮件等外部副作用。
