# 人体剪影来源与转换

当前组件使用 `bodySilhouette.ts`，替代上一轮 `bodyLineArt.ts` 的服装线稿。

- 来源：用户于 2026-10-21 在当前会话提供的 `codex-clipboard-557e570a-8a6c-40fd-ae9b-1693a41ddde3.png`（712 × 460 像素），并明确要求参考该图重新绘制。左侧男性，右侧女性。
- 原图 SHA-256：`efe2f0708a980549a6d3121746b839bf7de1fd1ad78b52cb516fc70b96194edf`。
- 先对灰度图进行 σ=0.85 像素的高斯去噪，再以灰度 140 为阈值提取两个主要黑色外轮廓，采用 1 源图像素的轮廓简化与保守 Cardinal 曲线平滑（男 127 节点，女 115 节点）。保留手臂与躯干、指间和双腿之间的留白，不填补原图负空间。
- 男性边界为原图 `(162, 23, 141, 402)`，女性为 `(392, 28, 113, 397)`；各自等比缩放至头顶 `y=35`、脚底 `y=613`，水平居中于 `x=200`，没有拉长腿部或重画体型。
- 输出只有轮廓路径，不包含原图白底、内部解剖结构或衣物线。采用统一中性灰填充，叠加交互测量路径。
- 附件只有正面轮廓。正背面交互共用该无内部细节剪影，通过视角标签与肩背测量路径表达方向，不虚构附件未提供的背部细节。

用户提供图片用于此次编辑；原图作者与外部许可未随附件提供，不将它标注为公共领域素材。上轮线稿来源记录保留供历史追溯。
