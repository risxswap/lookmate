# 人体线稿来源与修改

原作：[Human Male And Female Body Line Art](https://openclipart.org/detail/314881/human-male-and-female-body-line-art)，作者 GDJ，2019-02-06 上传。

- 原始 SVG：https://openclipart.org/download/314881/1549491622.svg
- 同作品镜像：[FreeSVG](https://freesvg.org/1549491622)，标注 Public Domain / CC0。
- Openclipart 的作品许可：[Public Domain / CC0](https://openclipart.org/share)。
- 取得日期：2026-10-21。

`bodyLineArt.ts` 从原作四组路径提取男女正背面，保持原有比例及不完全对称的自然站姿；统一到头顶 y=35、地面 y=613 的坐标系，四舍五入至三位小数。删除面部五官、乳头及生殖部位细节、部分胸部和腹股沟线，调整线色。组件另加简洁运动内衣及内裤线条，并在其上叠加交互测量线。并非基于用户尺寸生成的人体模型。

原作包含多段开放曲线，按原路径保留，不将其误作可直接填充的封闭轮廓。`bodyLineArt.ts` 仅含静态 SVG path 数据，不含外部资源、脚本或事件属性。
