# 用户 Web 协作约定

本文件适用于 `apps/web/`，同时遵循根目录的 [项目协作约定](../../AGENTS.md)。

## UI 组件库

- 页面统一使用 Ant Design（`antd`）作为 UI 组件库，版本沿用项目依赖与锁文件。
- 按钮、表单、菜单、弹窗、反馈等通用交互优先使用 Ant Design 组件；照片展示、衣橱和设计结果等业务界面在其基础上组合，并按需编写布局样式。
- 主题通过应用级 `ConfigProvider` 统一配置，优先使用主题 token 调整颜色、圆角与组件样式。

## 列表新增入口

遵循[架构设计中的前端列表操作布局](../../docs/01-项目总览/03-架构设计.md#前端列表操作布局2026-10-24已确认)：新增入口放在内容区内，与筛选同行靠右；空列表不重复提供新增按钮。局部创建操作保留在所属面板或弹窗。
